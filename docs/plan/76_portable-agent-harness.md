# Portable project agent harness

Maintain one project guide and one source for scoped rules, skills, reviewers and hooks. A standard-library Go doctor renders the native adapters for Claude Code, Codex and Antigravity CLI. Every new session checks its current worktree and returns a host-native receipt. CI checks all three offline.

Retain the platform commit verification policy, bounded issue reader and independent verification ladder. Run regular reviews in two fresh conversations that inherit the development model. The response contract and native permissions of each role are acceptance criteria. Rehearse discovery, invocation, rule lookup, permission decisions and damaged-file recovery with actual clients.
