- **A `self_hosted` session or deployment now refuses a `github_repository` resource** ([#322](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/322)) — nothing could ever clone one there: the BYOC worker mounts files and memory stores but no repository, so the session was created with a sealed token and a repository that never appeared. Session create, deployment create and deployment update now answer 400 in the reference's own sentence, "Environment env_... is a self-hosted environment. `resources` are not supported with self-hosted environments." A deployment stored earlier fails each fire as `self_hosted_resources_unsupported_error`, which pauses its schedule. `file` and `memory_store` resources stay accepted on `self_hosted`. A worker-side clone (#322) will not be built.
