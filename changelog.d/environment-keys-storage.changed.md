- **Environment keys become per-host: named, individually revocable, expiring** ([#43](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/43), plan 30 slice 1) — a BYOC worker credential used to be *the* credential: `EnsureEnvironmentKey` made a supplied value the one live key for an environment and revoked whatever it replaced, an invariant migration 0013 pinned in the schema. That model cannot express what a fleet needs — revoking one compromised host without disconnecting the rest — so it is retired in favour of the reference console's: `IssueEnvironmentKey` **generates** the secret itself (256 CSPRNG bits behind an `sk-map-env01-` prefix, deliberately not an Anthropic-look-alike), returns it exactly once, and stores only its SHA-256 hash, alongside a **name** and an expiry one year out. An environment now holds as many live keys as it has hosts; `ListEnvironmentKeys` pages them newest-first and `RevokeEnvironmentKey` retires one alone — idempotent, and scoped to the owning environment, so a key id can be neither revoked nor confirmed to exist through another. Migration 0021 adds the two columns, drops `environment_keys_one_live`, and takes the plain `environment_keys(environment_id)` index that partial-unique one had been quietly serving for both the per-environment lookup and the cascade from `environments`. Dropping it does not reopen the concurrent-mint race ([#72](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/72)) — that race was two mints silently sharing one slot, and per-host issuance has no shared slot — and `key_hash` stays UNIQUE, so a key value still binds to one environment for life. Expiry is enforced where it matters: an expired key fails authentication exactly as a revoked or unknown one does, one 401 with one message, so the auth lane is no oracle for which it was. Keys minted before this carry no name and no expiry and keep working until revoked — backfilling an expiry from `created_at` would have retro-expired credentials a running worker is authenticating with. No wire shape changed: `/v1` is untouched, and a compliant `ant beta:worker` sees the same Bearer lane it always did.
