- **A custom tool can no longer be named in the `mcp__` frame an MCP tool is offered under** ([#573](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/573)) — an agent create or update whose `tools[]` holds a `custom` tool named, say, `mcp__deepwiki__ask_question` now answers 400 `invalid_request_error` `tools.1.custom.name: custom tool name "mcp__deepwiki__ask_question" uses reserved MCP tool prefix` (under `agent.` on update), as the reference was recorded answering. Such a name used to be stored, and the brain then gave it to the custom tool and dropped the MCP tool it shadowed. An agent stored with one keeps resolving, and the brain still settles that contest by declaration order, as it does for a session's tool override, which is not checked. The 64-byte ceiling on a composed MCP tool name is unchanged; #573 stays open for it.
