- **A custom tool's name is held to 1–128 letters, digits, underscores and hyphens** ([#987](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/987)) — Agent create and update, a session create's tool override and a mid-session `agent.tools` update now refuse a custom tool name past 128 characters, an empty one, or one with any other character. Each answers 400 `invalid_request_error` in the words the reference was recorded giving on that route. Before, any name was accepted, and every turn of such an agent then failed at an Anthropic-protocol model endpoint. A leading digit or dash is still accepted. An agent stored with such a name before this change still resolves. A mid-session update now names a refused custom tool under `session.agent.config.`, as the reference does, where it used `agent.` before.
