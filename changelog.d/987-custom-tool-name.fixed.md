- **A custom tool's name is held to 1–128 letters, digits, underscores and hyphens** ([#987](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/987)) — agent create and update, a session create's tool override and a mid-session `agent.tools` update now refuse a custom tool name longer than 128 characters or holding any other character, with 400 `invalid_request_error`. Each route answers the length in the words the reference was recorded giving there; the character class takes its recorded agent-create words under each route's path. Before, such a name was accepted, and every turn of the agent then failed at an Anthropic-protocol model endpoint. An empty name, refused before in this platform's own words, now draws one of these refusals. A leading digit or dash is still accepted. An agent stored with such a name still resolves, and its turns still fail there. Agent update now names a `name`, `description`, `system` or MCP server `name` past its bound without the `agent.` prefix, as the reference was recorded naming a tool name's length on update.
