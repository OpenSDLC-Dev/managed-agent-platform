- **A brain test no longer asks a loaded host to renew a quarter-second lease seven times** ([#392](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/392)) — `TestLongTimeToFirstTokenKeepsLease` failed once under full-suite load with `lease keeper: queue: extend …: context deadline exceeded`, and the issue proposed that a lease extension timing out on a slow host is indistinguishable from a lease genuinely taken by another brain — which would mean a turn that streamed a real answer being abandoned without committing. The arithmetic says otherwise, and it is the lease keeper's own: it renews at `ttl/3` and bounds each attempt at `ttl - ttl/3`, so an attempt that exhausts its budget began a third of a lease in and ran to the end of it. **By the time an extend times out, the lease really has lapsed**, and abandoning is the correct reaction rather than a false positive — which is what the code comment already said. In production `LeaseTTL` is two minutes, so the budget is eighty seconds; the test pinned 250ms, leaving each extend 167ms and requiring seven in a row. The test now uses a one-second lease, quadrupling the margin while keeping what it exists to prove: the model still thinks well past a whole lease, so a keeper that stops renewing still lets the rival claim succeed. Nothing about the keeper changed, and the retry-and-backoff the issue reached for is deliberately not built — no evidence calls for it, and the case it would cover is stated in [docs/HISTORY.md](docs/HISTORY.md) if one ever does.
