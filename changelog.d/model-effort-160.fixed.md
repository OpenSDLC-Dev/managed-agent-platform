- **Honor explicit model effort** — Agent creation, updates, immutable versions and session overrides preserve `model.effort`, accept its string and object forms, and echo the normalized object. Invalid levels return 400; agent updates that omit effort retain it for the same model ID and reset to the upstream default when the ID changes. Session-level effort overrides are honored deliberately, unlike the reference service's documented ignored override. Primary, child-agent and outcome-grader requests forward it as Anthropic `output_config.effort` or OpenAI-compatible `reasoning_effort`. Omitted effort retains the configured upstream's default, and model-specific support remains the endpoint's responsibility rather than a hard-coded model table (#160).
