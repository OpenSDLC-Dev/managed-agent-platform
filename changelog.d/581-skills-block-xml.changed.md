- **The skills block in the system prompt now takes the reference's `<available_skills>` list** ([#581](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/581), plan 65) — the brain listed an agent's skills as prose bullets, each with a path relative to the sandbox workdir. It now writes an `<available_skills>` list with one `<skill>` per skill, holding `<name>`, `<description>` and `<location>`, the SKILL.md's path, as a recording of the reference shows. A short lead before the list tells the agent to read a matching skill's SKILL.md before it acts. On a `cloud` session the location is absolute, under the executor's workdir. The brain now reads `EXECUTOR_WORKDIR` for it, and the Helm chart sets it on the brain from `executor.sandboxWorkdir`; a deployment that sets the executor's workdir by hand sets the brain's too. On a `self_hosted` session the location stays relative, since the worker's workdir is the customer's.
