- **A dream's digest size is a target to write to in one pass, not a ceiling to trim to** — the pipeline's system prompt gave a digest's 4 KiB as a ceiling. In a live run at a hundred transcripts, the digest threads whose first draft was larger rewrote it again and again, a little shorter each time. Stage 2 spent its 300-turn cap that way, and the dream failed with `internal_error`. The nightly eval failed with that same error twice, and once on the dream's runtime budget. The prompt now gives 4 KiB as the size to aim at and asks for the digest in one pass, with no rewrite made only to shorten it; a fix to what a digest says is still allowed. Its one exception is a draft past 8 KiB, which it asks to rewrite once, to under 8 KiB. The prompt also asks for each fact in one place. The hundred-transcript eval now logs each stage's model turns, and each thread's turns, output tokens, time from first to last event, and tool calls, so a stage that runs long says which thread spent the turns.
