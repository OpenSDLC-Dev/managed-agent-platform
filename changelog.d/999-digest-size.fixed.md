- **A dream's digest threads no longer rewrite their digests to fit 4 KiB** — the pipeline's system prompt gave a digest's 4 KiB as a ceiling. When the model wrote a larger digest, its thread then rewrote it again and again, a little shorter each time. At a hundred transcripts the digest threads spent stage 2's 300-turn cap that way, and the dream failed with `internal_error`, or with `timeout` when its runtime budget ran out first. The prompt now gives 4 KiB as the size to aim at, says to write the digest once and not to rewrite it only to shorten it, and says to state each fact once. The hundred-transcript eval now logs each stage's model turns and each thread's turns, output tokens, run time and tool calls, so a stage that runs long says which thread spent the turns. (#999)
