- **Agent `system`, `name` and `description` are bounded on create and update (#665)** — `POST /v1/agents` and `POST /v1/agents/{id}` now refuse a `system` over 100,000 characters, a `name` over 256 and a `description` over 2,048 with 400 `invalid_request_error`, the reference API spec's bounds. Until now only a session's `agent_with_overrides` system was bounded, at the same 100,000. Characters are Unicode code points. Only a request that supplies an over-long value is refused. Agents already stored over a bound are grandfathered: they still start sessions, directly, pinned to a version or as a coordinator's roster member, their sessions still take `agent.tools`/`agent.mcp_servers` updates, and an agent update that does not resend the field still succeeds.
