- **A DeepSeek tool loop keeps its thinking through a prompt change, through the model gateway** (#883, #908, [docs/plan/61_thinking-replay-via-gateway.md](docs/plan/61_thinking-replay-via-gateway.md)) — DeepSeek refuses a tool continuation whose thinking is gone, and the brain dropped a loop's thinking whenever its system prompt or tool set changed mid-loop: a `system.message`, the dated `web_search` description at midnight, a resource or MCP tool added. The gateway now answers with `X-MAP-Thinking-Prefix: unchecked` when no upstream checks the answer's thinking against a prefix — DeepSeek's and MiniMax's Anthropic endpoints, probed, and every converted answer — and the brain sends that thinking back under any prefix, still only to the same model over the same route. A route straight to DeepSeek, not through the gateway, keeps the gap.
