- **A sandbox reaches the MCP servers its agent declares — plan 29 slice 6 (#45)** — `limited` networking's `allow_mcp_servers` now widens the per-session egress gate as well as the platform's own dial: the gate config carries the hosts the session's resolved agent declares MCP servers at, and a process inside the sandbox reaches them alongside `allowed_hosts`. The hosts ride beside the policy rather than folded into it, so an operator's own list is still served as written, and both ends fail closed — the control plane sends them only for a policy that can use them, and the gate admits them only under the same flag. A declared URL the platform would refuse to dial is not sent, since admitting its host would grant reach the flag never named, and neither is a wildcard-shaped one — an `mcp_servers` url passes no URL grammar, so `https://*.example.com/` would otherwise become the suffix rule a host set reads it as. This closes the MCP half of the gate's fail-closed divergence; `allow_package_managers` is still not honored (#50).
