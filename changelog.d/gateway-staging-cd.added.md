- **GCP staging's CD follows the model gateway switch** ([#909](https://github.com/OpenSDLC-Dev/managed-agent-platform/pull/909), part of [#906](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/906)) — `deploy.yml` reads whether the gateway runs off the chart's render of `staging-values.yaml`, before the build. While it runs, the workflow requires a twelfth repository variable, `MODELGATEWAY_SERVICE_ACCOUNT`, annotates the gateway's ServiceAccount with it and reads the annotation back, and expects a fourth Cloud SQL proxy; `mode2-secret.sh`, under `MODELGATEWAY=true`, writes `brain-api-key` from Secret Manager in place of `model-providers.json`, refusing a key the control plane or the gateway would refuse at startup. `staging-values.yaml` still turns the gateway off, so staging deploys as before; turning it on is that line, the operator's `foundation/` and `environment/` apply, the new secret and variable, and a catalogue deployment for the brain's model.
