- **The model gateway answers a Messages request from a Gemini model** (plan 62, [#900](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/900)) — a provider on the new `gemini` profile reaches the Gemini API with an API key (`x-goog-api-key`); a credential allowed only on its Gemini endpoint serves `/v1/messages` and `/v1/responses` by converting the request to `generateContent` and the whole answer back. A function call's thought signature comes back in a leading thinking block, which the caller returns, and goes back to the deployment that produced it; elsewhere a placeholder Gemini accepts stands in for it. A field Gemini has no counterpart for is refused, naming it, or goes to the alias's other targets; Chat Completions, embeddings, rerank and `count_tokens` never convert to Gemini. Migration 0052 adds the provider's `gemini_base_url`. Every disposition is in [docs/DIVERGENCES.md](docs/DIVERGENCES.md).
