- **CI and the release images now build with the same pinned Go, 1.26.8** — `go.mod`'s new `toolchain go1.26.8` line is the pin. Every `actions/setup-go` step installs it; until now CI installed 1.26.0, from the `go` line. The [Dockerfile](./Dockerfile)'s build stages start from the official Go image at `1.26.8-bookworm`, pinned by its multi-arch digest. Before, they used the floating `1.26-bookworm` tag, which shipped whichever patch release was newest on the day of the build. So the standard-library fixes a release ships are the ones CI tested, and a release build can be reproduced. `make pins-test` now fails if a setup-go step stops reading `go.mod`, if a workflow sets `GOTOOLCHAIN`, or if any Go image reference in the tree names another release or has no digest. A local `go` older than 1.26.8 downloads 1.26.8 on first use, unless `GOTOOLCHAIN=local` is set.
