- **`grep` takes the reference's twelve search options** ([#827](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/827)) — The built-in `grep` tool's schema is now the one a 2026-09-02 recording showed the reference handing the model: `output_mode` (`files_with_matches`, `content`, `count`), `-i`, `-n`, `-A`, `-B`, `-C`/`context`, `type`, `glob`, `head_limit`, `offset` and `multiline`, each with ripgrep's meaning. The search still runs on the sandbox's GNU grep, now with GNU find choosing the files, so `type` uses ripgrep's type names and `glob` takes ripgrep's glob syntax, including `**`, `{a,b}` and `!` negation. `multiline` needs a grep built with PCRE, as the default `debian:stable-slim` image's is. How the answers are formatted was not recorded; [docs/DIVERGENCES.md](docs/DIVERGENCES.md) lists the choices made.
