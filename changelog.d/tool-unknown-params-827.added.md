- **`grep` takes the reference's twelve search options** ([#827](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/827)) — The built-in `grep` tool's schema is now the one a 2026-09-02 recording showed the reference handing the model: `output_mode` (`files_with_matches`, `content`, `count`), `-i`, `-n`, `-A`, `-B`, `-C`/`context`, `type`, `glob`, `head_limit`, `offset` and `multiline`, each answered as ripgrep 14.1.1 answers it. The search still runs on the sandbox's GNU grep and find: `type` takes ripgrep's type names, `glob` is one ripgrep glob (`**`, `{a,b}`, `!` negation) anchored at the working directory, `multiline` counts and prints line-spanning and empty matches as `rg -U` does, and `head_limit` stops the search once its page is full. Unlike ripgrep it reads no `.gitignore` file and skips `node_modules` in its place. `multiline` needs a grep built with PCRE, as the default `debian:stable-slim` image's is; the sandbox image now also needs an awk. [docs/DIVERGENCES.md](docs/DIVERGENCES.md) lists where it still differs from ripgrep.
