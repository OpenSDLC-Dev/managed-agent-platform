- **The six sandbox tools' schemas are closed, as the reference's were recorded** ([#822](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/822)) — `bash`, `read`, `write`, `edit`, `glob` and `grep` now carry `"additionalProperties": false`, and `edit`'s `old_string` carries `"minLength": 1`, two keywords a 2026-09-02 recording showed the reference handing the model. The Anthropic-protocol adapter sends them; the OpenAI-protocol adapter strips both from every built-in tool, as it does the web tools' keywords since [#682](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/682). The tools run as before: edit already refused an empty `old_string`, and the tools still ignore a property they do not know. The request does change: an Anthropic-protocol route in front of a backend that refuses these keywords (vLLM's `/v1/messages`, or a gateway in front of Gemini) now rejects the tool list of any agent with a built-in tool enabled, where turning the web tools off used to keep them out. The other recorded differences stay on purpose and are registered in [docs/DIVERGENCES.md](docs/DIVERGENCES.md): `bash`'s `restart` and `timeout_ms` and `edit`'s `replace_all`, which come from the SDK's typed inputs; relative `file_path`s, which the skills block relies on; and `read`'s `view_range`, `grep`'s properties and the six descriptions, which keep the SDK's shape and our wording.
