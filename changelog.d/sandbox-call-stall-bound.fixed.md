- **Per-call silence bound inside the Docker and Kubernetes sandbox transports** (#395). Both sandbox transports now bound individual calls by byte-level silence (`sandbox.StallGuard`, default `5m`, configurable via `SANDBOX_STALL_TIMEOUT` in `cmd/executor` and `cmd/worker`) and surface stalls as `sandbox.ErrStalled` rather than blocking until the 30m work-item stall budget expires. On Docker, every Engine API call tracks upload and download progress and closes stalled request pipes on cancellation; on Kubernetes, the SPDY transport enforces a raw `net.Conn` deadline and context cancellation across the HTTP 101 upgrade (`newConnectionAndStream`) and measures progress on SPDY data streams so 5s keepalive pings cannot mask a wedged stream. Timed `Exec` calls still guard handshakes and control RPCs while disarming the stream timer once running so silent commands up to `ExecRequest.Timeout` are not cut short.
