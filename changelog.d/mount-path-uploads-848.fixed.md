- **A file `mount_path` of `/uploads/<name>` mounts at `/mnt/session/uploads/<name>`** ([#848](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/848)) — The reference reads `/uploads` as the uploads directory itself: recordings of session create, `POST /v1/sessions/{id}/resources` and a deployment fire all mounted `/uploads/<name>` at `/mnt/session/uploads/<name>`, where this platform rooted it a second time, at `/mnt/session/uploads/uploads/<name>`. All three now mount where the reference does. A deployment still resolves the path when it is created or updated, so its echo shows the resolved path where the reference's shows the one given. Every other path roots as before, and one already under `/mnt/session/uploads` still passes through. A bare `/uploads` now names the uploads directory and gets the 400 `/mnt/session/uploads` gets, instead of mounting a file named `uploads`. Nothing is backfilled: sessions keep the paths they stored, and a deployment created with `/uploads/<name>` keeps firing at the doubled path until an update sends that spelling again.
