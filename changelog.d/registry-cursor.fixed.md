- **`make registry-check` works without a token again** ([#1029](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/1029)) — The registry guard listed issues by page number. Once the repository passed 1,000 issues and pull requests, GitHub refused page 11 to a request with no token, so a local run without `GITHUB_TOKEN` failed with a 422. The guard now follows the cursor URL that each page's `Link` header names as next. It follows that URL only on the API's own host, because each request carries the token when one is set. CI was not affected: `registry.yml` passes a token.
