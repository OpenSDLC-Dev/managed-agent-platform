- **Skills now serve the GA wire shape** — The Skills API was still serving the shape the reference retired on 2026-08-27, so no released SDK could create a skill against this platform in either direction: clients send `display_name`, which was rejected, while the platform wanted `display_title`, which no current SDK offers (#566). A skill now carries `display_name`, `latest_version_id` and a `source` object; a skill version carries only the six GA fields, addressed by a `skver_…` id or the alias `latest` rather than by a Unix-epoch number. `DELETE /v1/skills/{id}` now deletes the skill's versions with it, and deleting a skill's only version is refused instead — the reference's semantics in both directions. `display_name` is optional (deriving from the SKILL.md frontmatter `name`), capped at 255 characters, and no longer required to be unique; the skills-list `limit` ceiling rises to 1000, and the archive download sends the `Content-Disposition` filename the reference sends. Version ids mint as `skver_`, with the previous `skillver_` spelling accepted on input indefinitely and stored ids left untouched, so existing agent pins keep resolving. The design and the divergences it leaves are in `docs/plan/39_skills-ga-shape.md`, pinned to a recording of the live endpoint.
