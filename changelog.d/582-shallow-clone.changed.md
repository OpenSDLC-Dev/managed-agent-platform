- **A mounted repository is now a shallow clone in the reference's shape** ([#582](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/582), plan 63) — the executor cloned a `github_repository` in full, with one remote. Every checkout form is now depth 1 with no tags: the default branch, a branch, and a commit, which is fetched by its exact SHA instead of out of the full history. A repository with a long history therefore costs far less of the clone's byte budget and time. The `.git/config` takes the shape recorded inside a reference sandbox: remotes `origin` and `github` at the URL's `.git` spelling, both fetching every branch, `gh-resolved = base` on `github`, and `gc.auto = 0`. A branch checkout also gets the remote-tracking ref `git clone` leaves, so `git status` has an upstream. A commit the remote does not have still reports reason `checkout`. An agent that needs more history can run `git fetch --unshallow`, which needs a credential for a private repository.
