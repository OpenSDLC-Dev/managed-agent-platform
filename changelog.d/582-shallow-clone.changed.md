- **A mounted repository is now a shallow clone in the reference's shape** ([#582](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/582), plan 63) — the executor cloned a `github_repository` with its full history, every tag and one remote. Each checkout form now fetches one commit at depth 1 with no tags, a commit by its exact SHA (an annotated tag's id brings the tag objects too), so a long history no longer costs the clone's byte budget and time. The default-branch and commit forms no longer carry the other branches: `git fetch` brings them, with a credential for a private repository. A commit can now be any commit in the repository's fork network, which GitHub serves by SHA through the repository's URL; an app that takes a SHA from an untrusted source should check it first. A branch name go-git's name check refuses, such as one with `*`, is now refused before the remote is asked, with reason `checkout`; so is one holding a non-ASCII space, which go-git would cut short and fetch another branch for, with reason `internal`. The `.git/config` takes the recorded shape: remotes `origin` and `github` at the URL's `.git` spelling, `gh-resolved = base` on `github`, and `gc.auto = 0`.
