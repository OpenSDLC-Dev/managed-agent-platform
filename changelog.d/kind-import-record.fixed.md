- **The kind image fixture no longer requires an import record that `kind load` did not leave** ([#1025](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/1025)) — `TestHookedImagesOfParallelPackagesAreTheirOwn` failed on every local `make verify` against kind v0.30.0 on node image v1.34.0. That setup leaves only the image's tag, not the `import-<date>@sha256:<digest>` record, so the test reported the record as missing. CI's kind v0.33.0 on node image v1.37.0 leaves both and passed. `sandboxtest.LoadIntoKind` now asks the nodes after the load. Where no node holds the record, the load is handled as one whose record cannot be named, the path an archive without `index.json` already takes, and the test log says so. Where any node holds the record, every node must still hold it, and `Remove` still takes it off.
