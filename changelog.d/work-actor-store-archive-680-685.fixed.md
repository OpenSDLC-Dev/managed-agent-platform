- **Work objects carry `"actor": null`, and a memory store's first archive moves its `updated_at`, as the reference's do** ([#680](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/680), [#685](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/685)) — Every work object the work API returns, from poll, list, get, metadata update, ack and stop, now carries `"actor": null`: every recorded reference body has the key, and the published schema lacks it, so the typed Go SDK files it under `JSON.ExtraFields`. The work `id` stays `work_…` where the reference uses the session's id, a deliberate difference [docs/DIVERGENCES.md](docs/DIVERGENCES.md) records. The first archive of a memory store now sets `updated_at` to `archived_at`, as the reference and every other archive route here do, and a repeat archive changes neither. Stores archived before the upgrade keep the `updated_at` they had.
