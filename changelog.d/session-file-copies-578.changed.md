- **A mounted file is the session's own copy, as on the reference** ([#578](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/578)) — Every create, resources add and deployment fire mints a `files` row per file resource, echoed in `resources[].file_id`: a fresh id, session-scoped, never downloadable, with the upload's name, size, type and expiry. It shares the upload's object, so deleting the upload leaves the mount working; the object goes once no row names it. The default mount path and a deployment still name the upload. `GET /v1/files` without `scope_id` now leaves session-scoped files out, outputs included. Earlier sessions keep naming their uploads. **Upgrading:** migration 0046 locks `files` for its index builds (under 0.4s per million rows); binaries built before it are not supported against its schema (#856). [docs/DIVERGENCES.md](docs/DIVERGENCES.md) registers what is inferred.
