- **A mounted file is the session's own copy, as on the reference** ([#578](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/578)) — Session create, resources add and every deployment fire now mint a `files` row per file resource, and `resources[].file_id` echoes it: a fresh id, scoped to the session, never downloadable, with the upload's name, size, type and expiry. It shares the upload's stored object instead of copying the bytes, so deleting the upload leaves the session's mount working, and the object goes once no row names it. The default mount path still names the upload, and a deployment still echoes the upload's id. `GET /v1/files` without `scope_id` now leaves session-scoped files out, harvested outputs included; list them with `?scope_id=<session>`. Sessions created earlier keep naming their uploads. **Roll the brain and executor before the control plane** (migration 0046): an older executor's harvest deletes a session's copies, and an older brain grades them as deliverables. [docs/DIVERGENCES.md](docs/DIVERGENCES.md) registers what is inferred.
