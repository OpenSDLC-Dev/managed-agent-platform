- **MCP servers that host only the deprecated HTTP+SSE transport are reachable** ([#348](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/348)) — the reference documents an automatic fallback for such servers, and this platform now takes it. The MCP client still tries Streamable HTTP first. When the latest POST is answered 400, 404 or 405, its body is at most 64 KiB and not a JSON-RPC error, and no earlier POST succeeded, the client opens the server URL as a 2024-11-05 SSE stream and runs the connection over it. One stream carries every answer, so the per-request cap bounds the whole connection: 30 seconds for tool discovery, two minutes for a tool call. A stream that names a message endpoint on another origin fails the connection. When both transports fail, the error names both attempts. [docs/DIVERGENCES.md](./docs/DIVERGENCES.md) records the one recorded difference this platform keeps by choice: every connection tries Streamable HTTP first, with no memory of an earlier fallback.
