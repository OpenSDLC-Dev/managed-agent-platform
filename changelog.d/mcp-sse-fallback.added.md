- **MCP servers that host only the deprecated HTTP+SSE transport are reachable** ([#348](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/348)) — the reference documents an automatic fallback for such servers, and this platform now takes it. The MCP client still tries Streamable HTTP first. When the latest POST is answered 400, 404 or 405 and its body is not a JSON-RPC error, the client opens the server URL as a 2024-11-05 SSE stream and runs the connection over it. One stream carries every answer, so the per-request cap bounds the whole connection: 30 seconds for tool discovery, two minutes for a tool call. A stream that names a message endpoint on another origin fails the connection. When both transports fail, the error names both attempts. [docs/DIVERGENCES.md](./docs/DIVERGENCES.md) records the two recorded differences this platform keeps by choice.
