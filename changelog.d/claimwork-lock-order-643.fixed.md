- **A worker's poll no longer deadlocks against a session delete or interrupt** ([#643](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/643)) — A worker's poll racing the delete of, or a `user.interrupt` to, a `self_hosted` session with a memory store attached could fail one of the two with a 500. Migration 0043 drops the foreign key from `work_session_tokens` to `sessions`; deleting a session still removes its tokens. The migration holds `sessions` and `work_session_tokens` exclusively while it runs. If it deadlocks during a rolling upgrade with a replica still on the previous build, it rolls back and a later start applies it.
