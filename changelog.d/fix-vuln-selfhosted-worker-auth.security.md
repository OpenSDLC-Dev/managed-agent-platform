- **Restrict self-hosted worker credentials to `user.tool_result` on session event sends** — `POST /v1/sessions/{id}/events` now refuses `user.tool_confirmation`, `user.message`, `user.interrupt`, `user.define_outcome`, `user.custom_tool_result`, and `system.message` with `403 permission_error` when authenticated with a `self_hosted` environment key (`sk-map-env01-…`) or per-item work token (`wtk_…`). Worker credentials remain scoped to `user.tool_result` on `self_hosted` sessions, preventing a compromised worker credential from clearing `always_ask` tool gates (including platform-executed MCP calls) or driving session turns.
