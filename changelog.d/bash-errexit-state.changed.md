- **A `bash` tool call's command runs at the top level of the shell, as a script does** ([#938](https://github.com/OpenSDLC-Dev/managed-agent-platform/pull/938)) — the template used to run it inside a function of its own. `local` outside a function therefore fails with `local: can only be used in a function`, and under `set -e` that ends the call; a command that used `local` at its top level should use a plain assignment. `FUNCNAME` no longer lists the template's function.
