- **A repository stored before #922 no longer removes what the image ships at its path** ([#930](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/930)) — such a repository keeps the literal `mount_path` it was stored with, which can lie outside `/workspace`. A clone replaced whatever was at that path when the sandbox user could remove it, so one stored at `/usr` could remove the image's own programs. Outside `/workspace`, a clone now replaces only an empty directory. At a path that holds anything, such as `/usr` or `/etc`, it fails with a `github_repository_clone_error` and removes nothing. A repository at a path the image does not ship, such as `/opt/repo`, still clones, because a new sandbox has nothing there. Inside `/workspace`, a checkout that lost its `.git` is still replaced whole.
