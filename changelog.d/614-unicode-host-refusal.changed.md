- **A Unicode hostname is refused on the wire, in the reference's words** ([#614](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/614)) — an environment's `allowed_hosts` and a vault credential's `auth.networking.allowed_hosts` now answer 400 `invalid_request_error` to an entry holding a non-ASCII character, such as `bücher.example`. Before, they accepted it and stored its A-label, `xn--bcher-kva.example`. An MCP server `url` holding one now answers `mcp_servers.0.url: must be a valid URI` on agent create and update, a session create's override and a session update, each under its route's path; before, it was accepted. Write the A-label instead: both lists accept it, though the reference refuses it in an environment's list. A percent-encoded host is still accepted. An entry stored earlier reads back unchanged, and an update that sends it back is accepted. The executor's `WEBTOOL_ALLOWED_DOMAINS` still converts a Unicode name. [docs/DIVERGENCES.md](./docs/DIVERGENCES.md) records the evidence.
