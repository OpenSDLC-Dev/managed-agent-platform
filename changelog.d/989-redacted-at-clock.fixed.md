- **A memory version's `redacted_at` is the time it was redacted** ([#989](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/989)) — a redaction now stamps `redacted_at` with the database's `clock_timestamp()` at the update, which comes after the store lock. It used to take `now()`, which Postgres freezes when the transaction begins, and a redaction begins before it takes the lock. So a redaction that waited on the lock was dated before writes that committed while it waited, by the length of the wait. Nothing orders or filters on `redacted_at`, so only the displayed time changes. Versions redacted before this release keep their stamps.
