- **A hook refuses a `git push` to main** (`.claude/hooks/push_main_guard.py`, `make push-guard-test`) — main's GitHub protection refuses a force-push or a deletion but not an admin's plain push, so with permission prompts off this PreToolUse hook is the only check on that push. It refuses a push whose destination is main or master, `--all` and `--mirror`, and a bare push while main is checked out. A branch push, a force-push to your own branch and the release ritual's tag push run as before. Without python3, or in a checkout that does not have the script yet, it steps aside rather than block every Bash call.
