- **A hook refuses a `git push` to main** (`.claude/hooks/push_main_guard.py`, `make push-guard-test`) — sessions here run with permission prompts off, so this PreToolUse hook is the one check between a mistaken push and the default branch. It refuses a push whose destination is main or master, `--all` and `--mirror`, and a bare push while main is checked out. A branch push, a force-push to your own branch and the release ritual's tag push run as before. Without python3, or in a checkout that does not have the script yet, it steps aside rather than block every Bash call.
