- **The `grep` tool no longer takes a status the image's startup chose as ripgrep installed** ([#942](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/942), plan 67 PR 2) — the two steps that install ripgrep in a sandbox now take their exit status only where the step's own output frame arrived whole. Before, an image's `BASH_ENV` file that ended the install step's shell with status 0 made grep take ripgrep as installed, search again, and fail with an error about a binary gone again. Now grep answers a tool error that names the image's startup. A step that runs past its deadline still answers that the install timed out.
