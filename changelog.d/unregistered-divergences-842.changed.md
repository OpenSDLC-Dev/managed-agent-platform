- **Three more recorded answers adopted** ([#842](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/842)) — A work poll's `reclaim_older_than_ms` under 1 is now 400 `reclaim_older_than_ms: Input should be greater than or equal to 1`, and an unparseable one the same validator's integer sentence, where both used to mean the 5000 ms default. An agent create naming a `type: "anthropic"` skill the catalog lacks, or a version of one that does not resolve, is 400 ``Agent has invalid configuration: `skill_id` `…` not found`` (or `` … version `…` not found``) — so where the operator never ran `-import-anthropic-skills`, every anthropic skill reference is refused at create instead of skipped at run time; custom references, agent updates and session overrides are unchanged. And `x-should-retry: false` now rides the refusals the reference was recorded sending it on — the memory 409s, the skills, environment, file and work API refusals, unknown paths and every console refusal — so the SDKs stop retrying them; [docs/DIVERGENCES.md](docs/DIVERGENCES.md) lists them.
