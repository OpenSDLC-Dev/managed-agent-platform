- **Three more recorded answers adopted** ([#842](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/842)) — A work poll's `reclaim_older_than_ms` under 1 is now 400 `reclaim_older_than_ms: Input should be greater than or equal to 1`, and an unparseable one the same validator's integer sentence, where both used to mean the 5000 ms default; an over-large one is still clamped. An agent create naming a `type: "anthropic"` skill that exists nowhere, or a version of an imported one that does not resolve, is 400 ``Agent has invalid configuration: `skill_id` `…` not found`` (or `` … version `…` not found``); a reference to one of the reference's prebuilt skills (`docx`, `pdf`, `pptx`, `xlsx`) that `-import-anthropic-skills` has not provisioned is accepted as before, with a warning in the log. Custom references, agent updates and session overrides are unchanged. A self-hosted worker now downloads a skill pinned by a legacy numeric version by the version's id, as the reference's worker does; the control plane still takes the number from older workers. And `x-should-retry: false` now rides the refusals the reference was recorded sending it on — the memory 409s, the skills, environment, file and work API refusals, unknown paths and every console refusal — so the SDKs stop retrying them; [docs/DIVERGENCES.md](docs/DIVERGENCES.md) lists them.
