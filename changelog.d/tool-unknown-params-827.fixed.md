- **The platform's own sandbox scripts no longer run an image's shell startup file** ([#827](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/827)) — On an image whose `ENV BASH_ENV` file printed — as it loaded, or from an `EXIT` trap it set — a `glob` answer carried its words as paths. Every script the executor and the BYOC worker run in a sandbox for themselves — `glob`, `grep`, the file transfers, the memory sync, checkpoints, the exec wrapper — now starts as `bash -p`, which reads no startup file, imports no exported function and ignores `SHELLOPTS`; environment variables still apply. The `bash` tool's commands and a `config.packages` install still run with the image's startup file, now once per command where the exec wrapper used to run it a second time.
