- **`glob` reads only its own output, says when the image's bash is too old for it, and refuses a pattern too long to run** ([#827](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/827)) — On an image whose `ENV BASH_ENV` file printed — as it loaded, or from an `EXIT` trap it set — a `glob` answer carried those words as paths; `glob` now reads only what its own script printed between a begin and an end line, as `grep` does. On bash 3.2, which has no `globstar`, `glob` expanded `**` as `*` and answered without saying so; it is now a tool error naming the bash 4.0 it needs. And a `glob` whose pattern and path make a command past the 120 KiB one exec argument can carry is refused before it runs, with a tool error that says so.
