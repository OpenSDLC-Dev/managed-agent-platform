- **`DELETE /v1/agents/{id}` answers the reference's 404** ([#592](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/592)) — an agent cannot be deleted, only archived, here as on the reference. The request used to fall to the generic fallback, which answers 405 `invalid_request_error` `Method Not Allowed`. It now answers what the reference was recorded answering on sixteen live agents: 404 `not_found_error` with the message `not found`, and no `x-should-retry` header. The agent is not changed. A cleanup script that reads a 404 on DELETE as "already deleted" will now take a live agent for a deleted one, as it would against the reference; archive the agent to retire it. Every other unsupported method on the agent routes still answers 405.
