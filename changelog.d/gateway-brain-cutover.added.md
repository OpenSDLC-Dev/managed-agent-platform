- **The brain's platform key for the model gateway** (plan 59 slice 5, #896) — `BRAIN_API_KEY`, read by the control plane and the gateway, is the key the brain will call the gateway with. The control plane registers it in `api_keys` as `brain`, exactly as it registers `CONTROLPLANE_API_KEY` as `bootstrap`, rotating by restart; a boot with the variable unset archives the env-var-managed `brain` key. The gateway lets it call any model without a key policy, as it does the bootstrap key (a policy written for its row still applies, until a rotation to a new value makes a new row), and the admin API refuses it. Both binaries refuse to start when it equals `CONTROLPLANE_API_KEY` or carries leading or trailing whitespace, which HTTP trims in transit. Every control-plane replica must agree on it, set or unset.
