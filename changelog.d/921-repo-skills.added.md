- **Skills in a mounted repository are now announced to the agent** ([#921](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/921), plan 65) — a session that mounts a `github_repository` now gets the skills in the checkout's `.claude/skills/<name>/SKILL.md`, as the reference loads them. They follow the attached skills in an `<available_skills source="repo">` list, each with its name, description and path. A skill with no frontmatter or no description is listed with an empty description. To list them from the first request, the brain holds a cloud session's first turn, once, while the executor clones the repositories and scans each one, once. An agent whose `read` tool is off is told of none, as on the reference. Mounting a repository trusts its skills: anyone who can push to the mounted branch can change what the agent does. The new self-hosted security section says so.
