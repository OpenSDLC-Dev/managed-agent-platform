- **The deploy workflow no longer tells an operator the `model-providers` secret already exists** ([#755](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/755)) — it said the container was created by the `foundation/` apply, which creates only the two `<prefix>-db-*` containers. `model-providers` is stood up out of band along with `controlplane-api-key` and `database-url`, so on a fresh environment it is missing rather than empty, and `gcloud secrets versions add` — the one command the failure message named — fails with `NOT_FOUND` instead of working. The comment now says what creates it, and the error the operator actually sees names the `gcloud secrets create` that has to come first.
