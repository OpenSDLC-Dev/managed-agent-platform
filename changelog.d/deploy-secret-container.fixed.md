- **The deploy workflow no longer tells an operator the `model-providers` secret already exists** ([#755](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/755)) — it said the container was created by the `foundation/` apply, which creates only the two `<prefix>-db-*` containers. `model-providers` is stood up out of band along with `controlplane-api-key` and `database-url`, so on a fresh environment it is absent rather than empty, and `gcloud secrets versions add` — the one command the failure named — fails with `NOT_FOUND` instead of working. The failure now names the `gcloud secrets create` first and the version second, and its annotation says the secret must exist *and* carry a version rather than assuming it exists. [deploy/gcp/README.md](./deploy/gcp/README.md)'s "Continuous delivery" section, which owns who creates what, gains the create commands for all three of those secrets and no longer says Terraform reads back both database ones — it reads back one.
