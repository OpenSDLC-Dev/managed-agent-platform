- **A repository with a subdirectory now mounts from an executor run natively on macOS** (found while verifying [#582](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/582)) — the clone's working tree sits under the temp directory, which macOS reaches through a symlink, and go-billy's bounded filesystem read every nested file there as outside its root, so the checkout failed with reason `internal`. The temp directory is now resolved first. Executors in the published images run Linux and were not affected.
