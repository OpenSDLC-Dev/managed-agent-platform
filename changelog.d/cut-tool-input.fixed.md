- **A tool call cut off at the output cap runs with no arguments, as the reference runs it** — a tool input that stops before its JSON object is complete, or before it began, used to fail the whole turn with a session.error. The call now goes out with `{}` as its input. The tool answers it with its own required-argument error, and the turn goes on, so the model can make the call again. A complete call in the same response runs beside it. The anthropic adapter also ends a tool block still open at message_stop, when the stop reason is max_tokens or model_context_window_exceeded, instead of failing the stream. The brain logs a warning for each cut call. Any other malformed tool input still fails its turn. (#951)
