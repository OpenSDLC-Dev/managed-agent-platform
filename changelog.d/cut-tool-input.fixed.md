- **A tool call cut off at the output cap is answered instead of failing the turn** — a tool input that stopped before its JSON object closed used to fail the whole turn with a session.error. The call is now committed with `{}` as its input, stamped `deny`, and the platform answers it in the same commit with an error result that says it was cut off and how the stream ended. Nothing runs it: `{}` would be a broader call for a tool whose arguments are all optional. The turn goes on, so the model can make the call again with shorter arguments, and a complete call in the same response runs beside it. The reference dispatches the cut call with `{}` instead (docs/DIVERGENCES.md). The anthropic adapter also ends a tool block still open at message_stop, when the stop reason is max_tokens or model_context_window_exceeded, instead of failing the stream. Any other malformed tool input still fails its turn. (#951)
