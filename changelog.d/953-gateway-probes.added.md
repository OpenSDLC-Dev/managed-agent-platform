- **The model gateway checks a credential and tests a deployment, on demand** ([#953](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/953)) — two admin routes call the vendor, and both need the admin role. `POST /admin/v1/providers/{id}/credentials/{cid}/check` lists the vendor's models with the credential's key, once on each protocol the key may use, and costs no tokens. Each protocol's result carries the vendor's status, its error, the latency and the model ids it listed. A profile's new `list_models` says where a check can list: DeepSeek's and Moonshot's Anthropic endpoints serve no such route, so a check answers from the profile there. `POST /admin/v1/deployments/{id}/test` sends one minimal request, a single token of chat or one short embeddings or rerank input, through the path an agent's call takes. It tests each enabled credential at once, or the one `credential_id` names: each once, without a retry, and within 30 seconds. Each result carries the vendor's own status, error type and message, the latency and the token usage. Each request a test sends is written to the ledger under `api_key_id` `admin` and `endpoint` `deployment_test`. Neither route stores its result, and neither runs when a provider or a credential is created.
