- **The model gateway converts a Messages request for an OpenAI-only credential** (plan 59 slice 4, [#PRNUM](https://github.com/OpenSDLC-Dev/managed-agent-platform/pull/PRNUM)) — a credential allowed only on its provider's OpenAI endpoint now serves `/v1/messages`: the request goes to the vendor's `/chat/completions` as Chat Completions, and the answer, whole or streamed, comes back in Messages, `reasoning_content` as a thinking block the caller returns to the deployment that produced it. A credential that can pass through always does. A field with no Chat Completions counterpart is dropped where a vendor would ignore it and refused otherwise; such a request goes to the alias's passthrough attempts, or is answered 400 naming the field. `count_tokens` is never converted: with only conversion attempts it answers 404. The conversion lives in `internal/modelgateway/convert`, which the brain's OpenAI-protocol adapter now shares. Every disposition is in [docs/DIVERGENCES.md](docs/DIVERGENCES.md).
