- **A past `expires_at` on an `mcp_oauth` credential is refused** ([#589](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/589)) — `POST /v1/vaults/{id}/credentials` with an `mcp_oauth` credential whose `auth.expires_at` is not in the future now answers 400 `invalid_request_error` `auth.expires_at must be in the future.`, the reference's recorded words. It used to store the credential, which then refreshed on its first dial. A credential update that sets such an `expires_at` is refused the same way, by inference, since only the create was recorded. An update that clears the field with `null` still works.
