- **`make gcp-env-start` brings the parked node pools back again** ([#914](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/914)) — GKE reports no `initialNodeCount` for a node pool at zero nodes, and `env-power.sh` took the empty answer for a pool still running: `start` started Cloud SQL, resized no pool, and still cleared the `power-saved-*` labels, leaving staging without nodes and without the marker that says it is parked. `status` printed a blank count, and `stop` resized pools already at zero again. An empty count now reads as zero, while a count gcloud fails to report still stops the script instead of reading as zero. A cluster a failed `start` left this way comes back by resizing its pools by hand.
