- **A deployment fire titles its session with the deployment's name** ([#678](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/678)) — `POST /v1/deployments/{id}/run` and a scheduled fire now create the session with `title` set to the deployment's `name`, as the reference does; the title used to be left empty. The session's `metadata` stays `{}`, which is what the reference sends too. Sessions fired before the upgrade keep their empty title.
