- **A session update accepts a patch that leaves an `mcp_toolset` naming no server** ([#1028](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/1028)) — `POST /v1/sessions/{id}` with `agent.mcp_servers: []`, on a session whose toolset named a cleared server, used to answer 400 `mcp_toolset references mcp_server …`. It now answers 200 and keeps the toolset, as the reference was recorded doing on an idle session. A `tools` patch that names an undeclared server lands the same way. Nothing dials a server the session does not declare, so the toolset offers no tools, and the brain's log line for it says the server is not declared. A call parked before the patch answers that the server is no longer configured. Agent create, agent update and session create keep the rule. [docs/DIVERGENCES.md](./docs/DIVERGENCES.md) records the evidence.
