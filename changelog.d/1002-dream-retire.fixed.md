- **A dream retires a memory whose subject a transcript ends, instead of rewriting it as news of the end** — the merge rules let a dream change a memory that a transcript contradicts, or remove it (in place: retire it as a tombstone), but did not say which. The nightly's in-place eval seeds a memory about a vendor portal and a transcript that says the portal was shut down. On two of eleven nights the dream rewrote that memory as news of the shutdown, so it retired nothing and its index listed nothing for the caller to remove. The rule now decides by what the memory is about, the thing its title names. Where that thing still stands and a fact about it changed, the dream changes the memory. Where a transcript ends it, the dream removes or retires the memory, and states what took its place in a memory of its own. The in-place eval now asks for the retired memory's path after the word "remove" in the index, because the tombstone's own index line names it either way, and it logs what the retired memory reads.
