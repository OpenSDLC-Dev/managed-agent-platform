- **The model gateway serves Anthropic Messages** (plan 59 slice 2, [docs/plan/59_model-gateway.md](docs/plan/59_model-gateway.md)) — `cmd/modelgateway`, a fifth server binary in the server image, answers `/v1/messages` (streamed and not), `count_tokens` and `/v1/models` for a platform API key its key policy covers. Each request passes through to the vendor deployment an alias routes to, only its `model` changed, and the answer comes back event by event. A failed attempt moves to the next credential, deployment or priority group, always before the caller's first byte, and a session id keeps a conversation on one upstream. Compose and Helm do not run it yet.
