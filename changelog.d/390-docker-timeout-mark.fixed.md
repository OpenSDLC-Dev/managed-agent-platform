- **A tool call the docker sandbox timed out is no longer reported as an ordinary kill** ([#390](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/390)) — the deadline was always enforced correctly; what could go wrong was the *label*. `Exec` decided `TimedOut` from two probes of the command's process, each keeping its own clock, and on a loaded host those goroutines can be scheduled after the watchdog's kill has already landed — at which point the daemon answers, honestly, that the process is gone. Both terms came back false beside an exit code of 137, and the model was told its command died rather than that it ran too long, losing the one signal that distinguishes "too slow" from "crashed". The watchdog now **marks its own kill**, between the `kill -0` that confirms the command is there and the `kill -9` that ends it, and the classification reads that mark as a third witness — the only one that does not depend on when a probe was scheduled. The k8s backend lost the same classification to the same race ([#95](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/95), [#110](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/110)) and was answered the same way; the two backends now run the same `classifyTimeout`, case for case, which is what a shared contract suite is worth. The mark is a `mkdir` rather than a file, so that nothing a tenant plants at the path can block the watchdog before it kills — the one failure that would be worse than the mislabelling. It is read out of band, through the archive endpoint the daemon answers for, and only when the answer could still change the verdict, so no extra round trip is spent on a command that finished cleanly. **This narrows a rule the docker backend used to hold absolutely**: its wrapper kept no state inside the container at all, because the first design's marker file "let a command forge a timeout it never hit, or erase one it did". The mark is safe where that was not, because it is one OR-term beside two host-measured ones rather than the evidence itself — forging one mislabels the tenant's own tool call and requires exiting 137 to be believed, suppressing one returns the verdict to the probes, and `overran`, which carries the deadline's actual guarantee, never reads it.
