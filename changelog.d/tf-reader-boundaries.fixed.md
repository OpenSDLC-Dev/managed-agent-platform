- **The two `.tf` readers answered over files Terraform refuses** ([#761](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/761)) — `deploy/gcp/check_split.py` and `tools/kmsrole/hcl.go` both closed a heredoc whose terminator is a file's last line with no trailing newline, which Terraform answers `Unterminated template string`: at depth 0 nothing fired, and inside a block the unbalanced-brace refusal fired and blamed a brace. Both also mishandled a carriage return that ends no CRLF — one translated it into a line break, the other read the file as a single line and left everything after the first header unread, neither saying so. Both now refuse a lone return among structure, in a heredoc body and inside a quoted string including behind a backslash, read one inside a comment, and read a file written entirely in CRLF. A byte that is not UTF-8 is likewise refused outside a comment, where it hid the header it was glued to, and read inside one. One known false refusal comes with this: a comment inside a template interpolation is not recognised as a comment, so a return there is refused although Terraform reads it ([#767](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/767)).
