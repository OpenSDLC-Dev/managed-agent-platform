- **The two `.tf` readers answered over files Terraform refuses** ([#761](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/761)) — `deploy/gcp/check_split.py` and `tools/kmsrole/hcl.go` both closed a heredoc whose terminator is a file's last line with no trailing newline, where HCL wants the newline and terraform answers `Unterminated template string` — it accepts the same bytes once one is added, and accepts an ordinary last line without one, so the rule belongs to the terminator. Inside a block the unbalanced-brace refusal then fired and blamed a brace; at depth 0 nothing fired at all. Both now name it. Both also mishandled a carriage return that ends no CRLF, which terraform refuses as an `Invalid character` wherever it sits: Python's `read_text()` translated it into a line break and parsed on, while Go breaks on `\n` alone and read the same bytes as one line, where only the first block header can match and the rest went unread with nothing said. Both now refuse the file, and both still read one written entirely in CRLF, which terraform accepts. Each reader's contract is that it refuses rather than answering from a place it has lost; these were the last two boundaries where neither did.
