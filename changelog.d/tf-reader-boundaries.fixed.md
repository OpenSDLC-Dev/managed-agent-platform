- **The two `.tf` readers answered over files Terraform refuses** ([#761](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/761)) — `deploy/gcp/check_split.py` and `tools/kmsrole/hcl.go` both closed a heredoc whose terminator is a file's last line with no trailing newline, where HCL wants the newline and terraform answers `Unterminated template string` — it accepts the same bytes once one is added, and accepts an ordinary last line without one, so the rule belongs to the terminator. Inside a block the unbalanced-brace refusal then fired and blamed a brace; at depth 0 nothing fired at all. Both now name it. Both also mishandled a carriage return that ends no CRLF, which terraform refuses as an `Invalid character` among structure, inside a quoted string and inside a heredoc body — though not inside a comment, which runs to the newline and reads it as ordinary text. Python's `read_text()` translated one into a line break and parsed on, while Go breaks on `\n` alone and read the same bytes as a single line, where only the first block header can match and the rest went unread with nothing said. Both now refuse it where terraform does, read it where terraform does, and still read a file written entirely in CRLF. Each reader's contract is that it refuses rather than answering from a place it has lost; these were the last two boundaries where neither did.
