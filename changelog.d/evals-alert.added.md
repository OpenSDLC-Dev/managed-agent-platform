- **The nightly eval suite now reports when it fails or stops** — a new scheduled workflow, `evals-alert.yml`, reads the `evals` run history every six hours and keeps one issue labelled `evals-failure` open while the newest verdict is a failure or is more than 48 hours old, then closes it when a run passes. A run that ends `cancelled` carries no verdict. The age check is the part a red job cannot report: from 2026-10-07 one run stuck in `waiting` held the `evals` concurrency group, every later scheduled run was cancelled, and no eval ran for ten days unnoticed (#950). The decision lives in `.github/scripts/evals-health.sh`, run by `make evals-alert-test` in CI.
