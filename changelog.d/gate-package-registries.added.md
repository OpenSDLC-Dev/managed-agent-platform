- **A `limited` sandbox reaches the package registries its environment opens (#591)** — `allow_package_managers` now widens the per-session egress gate, where it had parsed and then done nothing. The set is two hosts, `pypi.org` and `files.pythonhosted.org`, because that is what any evidence names: no Anthropic source publishes a list, and the one recording of the flag probed those two and a control. npm, cargo, gem, go and apt stay refused rather than guessed — a host the set omits is refused and never leaked, while a guessed one would open a `limited` sandbox wider than the reference (#594 sizes the rest). Three properties come with it: the flag alone opens the set, independently of what `config.packages` lists; matching is per host rather than per endpoint; and a dial only this widening admits is held to the platform's address floor, as a declared MCP endpoint's already is and an operator's own `allowed_hosts` deliberately is not.
