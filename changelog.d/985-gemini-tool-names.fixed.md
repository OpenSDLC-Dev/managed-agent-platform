- **A tool name that starts with a digit or a dash works on a Gemini upstream** ([#985](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/985)) — a Messages tool name may start with a digit or a dash, but a Gemini function name must start with a letter or `_`, and Gemini refused the whole request over one such name. The model gateway's conversion to a Gemini upstream now sends such a name with a `_` in front, so `1password` goes out as `_1password`, and reads the model's call back under the tool's own name, whole and streamed. A name of 128 characters that the `_` takes past Gemini's bound goes out shortened, as on a Chat Completions upstream. Two tools whose names would go out as one, such as `1password` and `_1password`, cannot be converted. No built-in or MCP tool name was affected: the built-ins start with a letter, and an MCP name with `mcp__`.
