- **Preserve model inference geography on the wire (#433)** — Agent models now accept and echo `inference_geo` (`us` or `global`) through immutable versions, session overrides and roster snapshots. Supplying a replacement model with the field omitted or null clears it; invalid selections return 400. This is protocol compatibility for deployments using operator-configured geography: the stored value does not alter provider requests or routing, and does not attest to where inference runs. Workspace geo policies and regional enforcement remain outside this platform's scope.
