- **Plan 30 archived — console-issued environment keys accepted against the real `ant` CLI** ([#43](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/43), [docs/plan/30_environment-keys-console-issuance.md](docs/plan/30_environment-keys-console-issuance.md)) — the issue asked that "an operator can issue and rotate an environment key, and a real `ant beta:worker` authenticates with it end to end (no manual DB edits)", and that is what ran: a key issued by curl against the console API drove a real `ant beta:worker poll` built from the read-only CLI checkout, confirmed positively rather than by silence — the platform's own `…/work/stats` reported a non-zero `workers_polling`, which only an authenticated poll can produce, while answering 401 to the management key, so the worker lane is demonstrably the lane in play. Revoking through the console returned a bodiless 204 and the running `ant` process printed the platform's `authentication_error` envelope and exited. The property the retired rotate-on-mint model could never offer was proven directly, beyond what the issue asked: two named keys, two real workers, revoke one — that host's process exited on the auth error while the other kept polling with a still-valid key and a still-empty log. No manual database access at any point; the only process touching Postgres was the control plane. The full transcript, including why the run used its own throwaway control plane rather than the shared compose stack, is in [docs/HISTORY.md](docs/HISTORY.md). **The plan archives with one of its own criteria unmet rather than met**: slice 3's stronger wording asked to poll *until an item is pulled*, and that is superseded by [#363](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/363). The blocker is causal — three sites enqueue `tool_exec`, but none can produce one without a pre-existing `agent.tool_use`, which no client may post, so it takes the live model route STATE.md has tracked as a blocker all along. What #363 still has to prove is queue delivery, work serialisation and the CLI's tool-runner half; what already holds by test is the issued-key auth boundary, the empty-poll route and revocation.
