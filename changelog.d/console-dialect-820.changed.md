- **The console namespace answers its recorded edges as the reference does** ([#820](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/820)) — **Deploy managed-agent-console with [console#187](https://github.com/OpenSDLC-Dev/managed-agent-console/pull/187) first**: an organization segment other than `default` is now a 401 `authentication_error` when it is a UUID (a 400 otherwise, not a 404), and an older console reads that 401 as its operator's token refused and signs them out. Environment keys are issued on `cloud` and archived environments (200, not 400), and the key listing takes a `limit` above 100. A `cloud` environment's key reaches nothing: its poll is a 400, its work listing a 404, its stats zeros with `workers_polling: null`, and the environment's sessions, their events, the files they mount and the skills answer it a 404. An archived `self_hosted` environment's key keeps working, so its queue drains. A management key's name is 1–500 characters as sent, untrimmed. API key create takes `principal_id`: a value that is not a `user_` or `svac_` id is a 400, a well-formed one a 404. What stays inferred is in [docs/DIVERGENCES.md](docs/DIVERGENCES.md).
