- **The console namespace answers its recorded edges as the reference does** ([#820](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/820)) — An environment key is now issued on a `cloud` or an archived environment (200, not 400). A `cloud` environment's key still cannot take that environment's work: its poll is a 400 and its work listing a 404, as recorded, and its stats report `workers_polling: null`. An archived `self_hosted` environment's key keeps polling, so its queue drains. The key listing takes a `limit` above 100 and echoes it. An organization segment other than `default` is a 401 `authentication_error` when it is a UUID and a 400 otherwise, instead of a 404; `default` stays the one organization served. A management key's name is 1–500 characters, taken as sent: no longer trimmed, so a whitespace-only name is accepted, and 501 is refused with the recorded message. API key create takes `principal_id`: a value that is not a `user_` or `svac_` id is a 400, and a well-formed one a 404, since there is no user or service account to link a key to. What stays inferred is registered in [docs/DIVERGENCES.md](docs/DIVERGENCES.md).
