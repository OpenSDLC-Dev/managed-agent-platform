- **Session creation is extracted into a transaction-scoped `createSessionTx`** (plan 37 slice 2, [#51](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/51)). `POST /v1/sessions`' transaction body — environment check, agent resolution, resource materialization, the session/thread/credential inserts, initial events — is now one function running inside a caller-supplied transaction, Begin/Commit and the post-commit metrics staying with the handler. Behavior-neutral: no wire shape, message or status changes, with the entire existing session suite as the regression test. The seam is what lets slice 3's `POST /run` and slice 4's scheduled fire create a session mid-transaction without a second copy of the platform's most load-bearing handler.
