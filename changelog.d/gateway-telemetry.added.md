- **The model gateway is traced and metered** (plan 59 slice 2, [#890](https://github.com/OpenSDLC-Dev/managed-agent-platform/pull/890)) — each request is a server span that continues the caller's `traceparent`, with one client span per upstream attempt beneath it, carrying the model name sent, the upstream model that answered, the status, error and tokens. By matched alias, deployment and key, `modelgateway.requests` and `modelgateway.request.duration` count every admitted request, `modelgateway.time_to_first_token` every stream, and `modelgateway.tokens` (input, output, cache write, cache read) and `modelgateway.cost` (the ledger row's) the usage an upstream reports, so a request whose upstream reported none adds to neither. A provider is sent trace context only when an operator sets its new `propagate_trace` field. A deployment price is now refused unless it is 0 or between 1e-12 and 1e15 per million tokens, so every cost the ledger computes from one reads back.
