- **The model gateway is traced and metered** (plan 59 slice 2) — each request is a server span that continues the caller's `traceparent`, with one client span per upstream attempt beneath it, carrying the model name sent, the upstream model that answered, the status, error and tokens. `modelgateway.requests`, `modelgateway.request.duration`, `modelgateway.time_to_first_token`, `modelgateway.tokens` (input, output, cache write, cache read) and `modelgateway.cost` (the ledger row's) count each admitted request by matched alias, deployment and key. A provider is sent trace context only when an operator sets its new `propagate_trace` field. A deployment price is now refused unless it is 0 or between 1e-12 and 1e15 per million tokens, so every cost the ledger computes from one reads back.
