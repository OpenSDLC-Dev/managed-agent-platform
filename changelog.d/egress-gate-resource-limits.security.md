- **Egress gate now enforces concurrent work, aggregate body-buffering, and container resource limits** ([#1052](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/1052); [plan 70](docs/plan/70_security-hardening-vault-egress.md) slice 2) — `internal/gate` now bounds concurrent plain-HTTP requests (default 64), concurrent CONNECT tunnels (default 64), aggregate plain-HTTP body buffering (default 32 MiB), and body read stalls (default 30 s) through a `Limiter` shared across `gaterun.SwappableHandler` policy swaps, while `cmd/gate` caps request headers at 64 KiB. Over-budget traffic returns `503` (or `408` on a stalled upload) without blocking ordinary requests, and buffered bytes are released once `RoundTrip` finishes. Both the Docker and Kubernetes sandbox providers now apply independent default resource limits to the gate container (256 MiB memory, 500m CPU, 128 PIDs on Docker, 64 MiB ephemeral storage on Kubernetes) even when sandbox memory limits are disabled.
