- **A pass that finds a mounted file gone lands that file alone, not every mount again** ([#860](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/860)) — When a session's file mounts were already in the sandbox and the agent moved one away, the next tool call re-streamed every mount, overwriting the agent's edits to all the others. Now only the missing mounts land again; a changed set of mounts still lands whole. Both the cloud executor and the self-hosted worker.
