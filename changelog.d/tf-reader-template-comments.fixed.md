- **The two `.tf` readers refused a comment Terraform reads** ([#767](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/767), folded into [#762](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/762)) — HCL allows an inline `/* … */` comment inside a `${…}` interpolation or a `%{…}` directive, and Terraform reads a carriage return, a U+FEFF or one of the five line-like separators in there as the comment text it is. Neither reader recognised the comment, so those characters reached the checks that refuse them among structure, and both rejected a file `terraform fmt` formats clean. Both now blank the whole `/* … */` span inside a template expression — and with it a quote, which the refusal aimed at a quoted string inside a template had been firing on. Only when the `*/` is on the same line: without one the template stays open past the end of the line, which Terraform answers `Invalid expression`, and guessing there is not something either reader does. `#` and `//` need no such care — inside a single-line template they swallow the closing brace and the quote, so Terraform refuses the file and so do both readers.
