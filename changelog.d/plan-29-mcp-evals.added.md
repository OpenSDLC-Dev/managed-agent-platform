- **The MCP path is covered by a live trial and a third-party server, and plan 29 is closed — slice 7 (#45)** — Two tiers that no in-process fixture can stand in for. The eval suite gains **`mcp-answer`**, its sixteenth trial: a passphrase that exists only in what an MCP server's tool returns, so a correct answer proves discovery, the brain offering the listing as `mcp__{server}__{tool}`, the confirmation round trip an `mcp_toolset` gates on by default, the executor answering the call, and the result reaching the next request. Its fixture listens on a private-range interface address rather than loopback, which is where every other fixture in the suite lives — the executor dials MCP servers with its own guarded client, and that guard refuses loopback because the platform's own surfaces are there. And **`RUN_LIVE_MCP_TESTS`** dials a server this repository did not write (`MCP_LIVE_SERVER_URL`, optional `MCP_LIVE_SERVER_TOKEN`): every other MCP test speaks to a fixture built from the same go-sdk the client is built from, so both ends share one understanding of the protocol and agree even where that understanding is wrong. The same opt-in contract the other live tiers have — consent is the environment variable and never the file, and an opted-in tier with no endpoint fails rather than skips; an absent token is an anonymous dial the protocol admits, not a rotted credential. With this, [plan 29](https://github.com/OpenSDLC-Dev/managed-agent-platform/blob/main/docs/plan/29_mcp-toolset.md) is archived: an agent with an `mcp_toolset` calls a real MCP server's tools, verified end to end through the real `ant` CLI against a public MCP endpoint (docs/HISTORY.md).
