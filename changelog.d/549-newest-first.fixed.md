- **The memories list is newest first, and refuses `depth=0` beside a `path_prefix`** ([#549](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/549)) — `GET /v1/memory_stores/{id}/memories` without a `depth` now lists memories by `created_at`, newest first, with `id` breaking a tie, as the reference was recorded answering. It used to list them in byte-wise path order. With `depth=1` the list keeps path order, as the reference documents. Each depth now pages with its own cursor and refuses the other's, so a `next_page` issued before this release answers 400 `invalid page cursor` on a list without a `depth`: start that walk again. `depth=0` beside a non-empty `path_prefix` now answers 400 `invalid_request_error` `depth: must be greater than or equal to 1`, as the reference does. Omit `depth` for the recursive list. `depth=0` without a prefix is still accepted.
