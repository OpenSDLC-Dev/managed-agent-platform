- **The memories list is newest first, and refuses `depth=0` beside a `path_prefix`** ([#549](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/549)) — `GET /v1/memory_stores/{id}/memories` without a `depth` now lists memories newest first, as the reference was recorded answering. It used to list them in byte-wise path order. It orders by `created_at`, with `id` breaking a tie; the recordings show neither choice, and docs/DIVERGENCES.md registers both. With `depth=1` the list keeps path order, as the reference documents, although its recorded `depth=1` pages followed another order. Each depth now pages with its own cursor and refuses the other's. So a walk of the list without a `depth` that spans the upgrade answers 400 `invalid page cursor` on its next page, whichever version issued the cursor: start that walk again. `depth=0` beside a non-empty `path_prefix` now answers 400 `invalid_request_error` `depth: must be greater than or equal to 1`, as the reference does. Omit `depth` for the recursive list. `depth=0` without a prefix is still accepted.
