- **A send to an archived session is refused in the reference's words** ([#58](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/58)) — `POST /v1/sessions/{id}/events` on an archived session still answers 400 `invalid_request_error`, before any event in the send is read. Its message is now "Cannot send events to archived session: <id>", as the reference was recorded answering, in place of "session <id> is archived and read-only". A client that matched the old text must match the new one.
