- **The model gateway quotes no upstream credential in two failures** ([#953](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/953)) — a caller's 502 for a Gemini answer the gateway could not convert quoted the vendor's `finishMessage` unredacted. The log line for a refused credential matched the key only as the vendor's body spells it, so a key the vendor echoed in a JSON string, escaped (`\/` for `/`), reached the log, and a refusal over 4 KiB was logged cut, where a key can straddle the cut. The 502's message is now redacted, a whole JSON refusal is decoded before it is redacted, and a cut refusal is no longer quoted. An operator whose vendor echoes keys may want to scrub older `modelgateway: upstream refused a credential` log lines.
