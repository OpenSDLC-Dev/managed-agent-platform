- **The model gateway sends each model only its own thinking** (plan 59 slice 2) — every signed thinking block and redacted block the gateway returns names the deployment that produced it, and a request sends each deployment only the thinking it produced, so a conversation that falls back to another model, or comes back, never hands an upstream thinking it cannot verify; thinking that arrives unsigned, and any after it in the same answer, names no deployment and goes back to none. A request is tried first at the deployment that produced its newest thinking. An upstream that refuses the thinking it was sent anyway gets the request once more without any, when its attempt budget allows; when that answer's thinking is signed and the caller sends it back, later requests leave out the thinking it was produced without.
