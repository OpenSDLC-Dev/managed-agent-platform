- **The registry guard's summary told a reader to re-run it when it had found rot** ([#742](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/742)) — `registry.yml` branched on the guard's exit code, 1 for findings and 2 for "GitHub could not be asked", but neither survives `make registry-check`: `go run` exits 1 whenever its program fails, and make reports any failed recipe as its own 2. So every finding was headed "GitHub could not be reached … re-run it". The summary now branches on zero against non-zero, as `sdk-bump.yml` already did, and leaves the output to say why; a run whose guard never started — a failed checkout or Go setup — no longer reads as findings.
