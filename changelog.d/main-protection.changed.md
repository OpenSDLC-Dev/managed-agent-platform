- **Main's branch protection now holds admins too** ([#920](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/920)) — it skipped admins, and sessions here push with an admin's token, so nothing stopped a mistaken `git push origin main`. Main now has "Do not allow bypassing the above settings" on, and requires a pull request with zero approvals. A direct push to `main` is refused for everyone, even one whose commit already has green `ci` and `coverage` checks. A merge still needs both checks green. A merge on red needs a maintainer to turn the bypass option off for the duration; CLAUDE.md says so.
