- **Main's branch protection now binds admins too** ([#920](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/920)) — it skipped admins, and sessions here push with an admin's token, so nothing stopped a mistaken `git push origin main`. Main now has "Do not allow bypassing the above settings" (`enforce_admins`) on, and requires a pull request with zero approvals. A push to `main` that is not a pull request's merge is refused for everyone, even when its commit already has passing `ci` and `coverage` checks. An admin's merge now needs those two checks to pass, as everyone else's did. CLAUDE.md says how the user makes an exception.
