- **The worker force-stops work whose heartbeat is refused or whose lease is not extended, as the SDK worker does** ([#813](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/813)) — when a heartbeat answers `lease_extended: false` beside a live state, or fails with a `4xx` other than `412`, `408`, `409` and `429` (a `404` for work that is gone, a `401` or `403` for a refused key), the bundled worker now cancels the run and force-stops the work item, as the reference Go SDK worker does. It used to release the item without a stop. A `412`, and transient failures that outlast the lease's TTL, still release it unstopped. A force stop that fails in turn is only logged, and the worker keeps polling. A heartbeat answered `409` is now retried, as the SDK worker retries it, instead of ending the run.
