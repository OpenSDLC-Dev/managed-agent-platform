- **Every refused request is logged** ([#540](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/540)) — Each 4xx answer writes one Info line, `request refused`, with the method, the path without its query string, the status, the error type and the request id, because several of the reference's sentences the wire now carries name nothing — `Not found`, `Cannot modify archived agent`. Detail that only the server knew and a sentence drops gets a line of its own beside it, with the same request id: the stale-version 409's expected and current versions among them.
