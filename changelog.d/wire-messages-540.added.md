- **Every refusal of an authenticated request is logged** ([#540](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/540)) — Each 4xx answered to a request a credential authenticated writes one Info line, `request refused`, with the method, the path without its query string, the status, the error type, the wire message and the request id; the path and the message are capped at 512 bytes. An unauthenticated request writes none, so it cannot drive the log's volume. The line exists because several of the reference's sentences the wire now carries name nothing — `Not found`, `Cannot modify archived agent`. Detail only the server knew and a sentence drops gets a line of its own beside it, under the same request id: the stale-version 409's expected and current versions among them.
