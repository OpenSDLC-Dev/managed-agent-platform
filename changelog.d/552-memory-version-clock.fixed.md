- **A memory version's `created_at` is the time it was written** ([#552](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/552)) — both writers of `memory_versions`, the memories API and a session's memory sync, now stamp each row with the database's `clock_timestamp()` at the insert instead of the column default `now()`, which Postgres freezes when the transaction begins. Before, every version one sync wrote shared one `created_at`, and a write that waited on the store lock was stamped earlier than the rows committed while it waited. The version list's order and paging are unchanged: they still break a tie on `id`. Events and session threads were already stamped this way.
