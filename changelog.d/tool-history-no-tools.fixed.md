- **A turn with tool history and no tools now defines a placeholder tool** ([#1021](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/1021)) — after a session update sets `agent.tools` to `[]`, clears both `tools` and `mcp_servers`, or disables a toolset, the next model request replays the earlier `tool_use` and `tool_result` blocks with no `tools`. Third-party references report that Anthropic's Messages API refuses that request with a 400, which would fail every later turn until tools come back. Such a request now carries one placeholder tool, `no_tools_available`, with `tool_choice` `none`, so the model can call nothing and the history is sent unchanged. `provider.Request` gains `ToolChoiceNone`, which the Anthropic and OpenAI adapters send. What the reference sends on this turn is unrecorded; [docs/DIVERGENCES.md](./docs/DIVERGENCES.md) records the inference.
