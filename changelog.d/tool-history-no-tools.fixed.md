- **A turn with tool history and no tools now defines a placeholder tool** ([#1021](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/1021)) — a session update that set `agent.tools` to `[]`, or cleared both `tools` and `mcp_servers`, left the next model request replaying the earlier `tool_use` and `tool_result` blocks with no `tools`. A disabled toolset did the same. Third-party references report that Anthropic's Messages API refuses that request with a 400, which would fail every later turn until tools come back. Such a request now carries one placeholder tool, `no_tools_available`, whose description tells the model not to call it, and the history is sent unchanged. A model that calls it anyway gets an unknown-tool error result and the turn goes on. What the reference sends on this turn is unrecorded; [docs/DIVERGENCES.md](./docs/DIVERGENCES.md) records the inference.
