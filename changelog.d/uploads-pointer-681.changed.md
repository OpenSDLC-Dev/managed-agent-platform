- **The system prompt points at `/mnt/session/uploads` instead of listing a session's file mounts** ([#681](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/681)) — The "Mounted files" block, one bullet per mount with its path, filename, MIME type and size, is replaced by the reference's own sentence as a recording quoted it: "User uploads (files uploaded to the session by the user) are available at `/mnt/session/uploads`. Use `ls` on that directory to see available files." No file is listed, so the agent finds its uploads with `ls`. A mount at its default path, `/mnt/session/uploads/file_<id>`, therefore no longer tells the model the original filename or MIME type; pass a `mount_path` that carries a meaningful name where that matters. The sentence still appears only while the session has at least one live file mount, and a file added to a session that already has one no longer changes the system prompt. A mount stored outside `/mnt/session/uploads` — possible only for a resource written by an unreleased build before [#323](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/323) — is still named, by path alone, after the sentence. The gating and the sentence's placement remain inferences, registered in [docs/DIVERGENCES.md](docs/DIVERGENCES.md).
