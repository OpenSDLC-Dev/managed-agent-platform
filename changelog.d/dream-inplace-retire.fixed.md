- **A dream's merge rules now say when a contradicted memory is retired rather than changed** — the rules let a dream change a memory that a transcript contradicts, or remove it (in an in-place dream, retire it as a tombstone), but did not say which. So a memory whose subject had ended could be rewritten as news of the end, and an in-place dream then listed nothing for the caller to remove. The rule now decides by the thing the memory's first line names. While that thing stands, the dream changes the memory. Once a transcript ends it, the dream removes or retires the memory and carries what still holds into another memory. Stages 1 and 3 say the same. The in-place eval now checks that the index lists the retired memory for removal, and that its successor fact survives outside the tombstone. (#1002)
