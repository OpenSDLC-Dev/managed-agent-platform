- **A dream's merge rules now say when a contradicted memory is retired rather than changed** — the rules let a dream change a memory that a transcript contradicts, or remove it, but did not say which. In an in-place dream, removing means retiring the memory as a tombstone. So a memory whose subject had ended could be rewritten as news of the end, and an in-place dream then listed nothing for the caller to remove. The rule now decides by the thing the memory's title or first line names. While that thing stands, the dream changes the memory. Once a transcript ends it, the dream removes or retires the memory and carries what still holds into the memory about it. Stages 1 and 3 say the same. An in-place dream's index now lists its tombstones in one form: a `## To remove` heading, then one `- <path>` line per tombstone, and no such heading when it retired nothing. The in-place eval checks that listing, and that the successor fact survives outside the tombstone. (#1002)
