- **The web tools hand the model the reference's definitions** ([#682](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/682)) — `web_fetch` and `web_search` now carry the schemas and descriptions a 2026-09-02 recording of the reference echoed. The schemas add `"format": "uri"` on `url`, `"minLength": 2` on `query` and `"additionalProperties": false` on both. The descriptions are long usage guidance. `web_search`'s query guidelines end with today's date in UTC, rendered per request, so the definitions, and any prompt cache keyed on them, turn over daily. The Anthropic-protocol adapter sends the keywords as recorded. The OpenAI-protocol adapter strips `format`, `minLength` and `additionalProperties` (and `unevaluatedProperties`) from the built-in tools' schemas, so a backend that accepts only part of JSON Schema does not reject the default tool list. Custom and MCP tool schemas keep every keyword on every backend. The executor refuses a `web_search` query under two characters, counted untrimmed; a blank query is still refused. `web_fetch`'s text says it fetches only URLs the user gave or a search returned; nothing enforces that here ([#823](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/823)), so the operator allowlist is the only bound on what it fetches. The six sandbox tools' recorded schema differences are registered and tracked in [#822](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/822).
