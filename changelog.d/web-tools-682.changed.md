- **The web tools hand the model the reference's definitions** ([#682](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/682)) — `web_fetch` and `web_search` now carry the schemas and descriptions a 2026-09-02 recording of the reference echoed. The schemas add `"format": "uri"` on `url`, `"minLength": 2` on `query` and `"additionalProperties": false` on both. The descriptions are long usage guidance where ours were one sentence. `web_search`'s guidance ends with today's date in UTC, rendered for each request, so the tool definitions change once a day and any prompt cache keyed on the request prefix turns over daily. That cost was accepted. The Anthropic-protocol adapter sends the keywords as recorded. The OpenAI-protocol adapter strips `format`, `minLength` and `additionalProperties` from every tool schema, at any depth, so a backend that accepts only part of JSON Schema does not reject the tool list. The executor refuses a `web_search` query of fewer than two characters, counted untrimmed, before calling the backend. A blank query is still refused. The six sandbox tools' recorded schema differences are registered and tracked in [#822](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/822).
