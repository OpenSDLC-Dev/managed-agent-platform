- **The management-key lifecycle now matches the reference on every point it was guessed at** ([#389](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/389)) — plan 32 shipped five INFERRED entries in [docs/DIVERGENCES.md](docs/DIVERGENCES.md): behaviours the original console recording never probed, where the platform had to choose. They were probed against the live reference console, and **three of the five went against us**. A **repeated archive is now refused** with a 400 instead of succeeding as a no-op — the reference answers `"Archived API keys cannot be updated."` to *every* patch on an archived row, the repeated archive included, which is what this platform did originally until a review round argued that a retried Delete should not error; sound in the abstract, and not what this API does. A key **disabled and then left to lapse now renders `expired`**, not `inactive` — the clock outranks the operator's own action, the opposite of what was inferred — and the precedence measured alongside it, `archived` > `expired` > the stored status, is now pinned in a test: a key archived after its expiry had passed reads `archived`. A **past `expires_at` is now accepted** on creation and mints a key born `expired`, where it used to be refused; the refusal had looked like the safe direction, and with it goes the database-clock guard that existed to stop a value lapsing between the route's check and the insert. Two further divergences surfaced that nobody had suspected, and both are closed the same way: the reference's own refusal states that an expired key *"can only be deleted, not renamed or reactivated"*, so a lapsed key now admits **archiving alone** where the disable and the rename had also been permitted, and an **empty patch** now answers 200 with the unchanged resource instead of `"at least one of status, name is required"`. The registry's INFERRED section loses all five plan-32 entries — not because they were confirmed, but because nothing is left to infer and, after this change, nothing is left to diverge on; the CONFIRMED entry describing client-supplied expiry loses the sentence that called a past instant refused. [docs/self-hosted-security.md](docs/self-hosted-security.md) §10 gains the precedence rule and the archiving-only rule in the operator's terms, and states that every rule in those paragraphs was measured rather than inferred. The probe run, including what it says about guessing at wire shapes, is recorded in [docs/HISTORY.md](docs/HISTORY.md).
