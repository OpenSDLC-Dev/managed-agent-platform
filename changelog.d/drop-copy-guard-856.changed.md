- **A session's file copy is deleted like any other row; rolling back below migration 0046 is unsupported** ([#856](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/856)) — Migration 0047 drops the copy-delete guard and tombstone trigger 0046 added for older binaries, and `map.copy_delete` with them; the reference count on the object-delete queue stays. **Upgrading:** binaries built before 0046 are not supported against this schema, so a rollback below it, a failed `helm upgrade --atomic` included, is unsupported.
