Session create now answers 400 in the reference's own sentence, "Environment env_... is a self-hosted environment. `resources` are not supported with self-hosted environments.", before the token reaches the secrets cipher. Deployment create and update answer with the same sentence; the reference's words there are unrecorded. A deployment stored earlier fails each fire as `self_hosted_resources_unsupported_error`: a scheduled fire also pauses it, and a manual run leaves it active. `file` and `memory_store` resources stay accepted on `self_hosted`. A worker-side clone (#322) will not be built.
