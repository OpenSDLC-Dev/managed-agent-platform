- **Password login throttling now separates unrelated clients behind `app-edge`** ([#1052](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/1052)) — `app-edge` (`native.caddy`) now overwrites caller-supplied `X-Platform-Client-IP` and `X-Platform-Edge-Token` headers with Caddy's observed transport client address (`{http.request.remote.host}`) and configured `APP_EDGE_CLIENT_IP_TOKEN`. In development password mode, `internal/login.Manager.Throttle` keys the per-client quota on `X-Platform-Client-IP` only when a single constant-time-verified `X-Platform-Edge-Token` matches `APP_EDGE_CLIENT_IP_TOKEN`, failing closed on malformed or repeated edge IP headers while ignoring generic forwarding headers (`X-Forwarded-For`, `Forwarded`, `X-Real-IP`) and preserving direct-request transport-peer throttling.
