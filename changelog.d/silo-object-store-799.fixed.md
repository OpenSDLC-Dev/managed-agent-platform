- **The bundled object store is now PGSTY Silo, a maintained MinIO fork** ([#799](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/799)) — MinIO has taken its community images off quay.io as well as Docker Hub (#701), so every machine without the image already cached lost it: the compose stack, the chart's in-cluster MinIO and the object-storage contract tests alike. All three now pin `pgsty/silo:RELEASE.2026-09-16T00-00-00Z` from Docker Hub, by digest as well as tag, and a test fails if they drift apart. Silo keeps what they depend on, so nothing else moves: the S3 API, `MINIO_ROOT_USER`/`MINIO_ROOT_PASSWORD`, the `/minio/health/*` routes, `server /data` and `mc` in the image. The chart's `minio.*` values, the compose `minio` service and the data volume keep their names. An existing bundled deployment picks up the new image on its next upgrade and serves the data volume it already has. `deploy/gcp`'s Docker Hub mirror can serve the image again, as `PREFIX/pgsty/silo`.
