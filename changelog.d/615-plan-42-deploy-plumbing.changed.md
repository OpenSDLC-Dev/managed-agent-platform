- **Plan 42's slice 1 now carries its deployment plumbing** ([docs/plan/42_multi-tenant-activation.md](docs/plan/42_multi-tenant-activation.md) §7.1, [#615](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/615)) — the slice that adds `IDENTITY_CLAIM_WORKSPACES` and `IDENTITY_WORKSPACE_MAP` must also let compose, the Helm chart and GCP staging set them. The chart renders the workspace map the way it renders the role map, and refuses a map entry it cannot encode and either half of the pair set alone. The first attempt at the slice (#616, closed unmerged) added the two names with no deployment able to set them, because the plan asked for no more. #615 recorded that gap and closes with this change.
