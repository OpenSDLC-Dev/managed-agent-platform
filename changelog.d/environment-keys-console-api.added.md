- **An operator surface for environment keys — issue, list and revoke over HTTP** ([#43](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/43), plan 30 slice 2) — until now a self-hosted operator had to reach into Postgres to give a BYOC worker its credential, because the reference mints environment keys from its **console**, on a private backend no SDK or CLI route touches. That surface now exists here: `POST /api/oauth/organizations/default/environments/{environment_id}/tokens` issues a key and returns it once as an RFC 6749 token response (`{"access_token":"sk-map-env01-…","expires_in":31536000}` — the plaintext's only appearance anywhere), `GET` on the same path lists an environment's live keys with their names, creation times and expiries but never a secret, and `POST …/tokens/{token_id}/revoke` retires one host's key alone, idempotently and 204-bodiless. All three take the management `x-api-key`; an environment key — the very credential they mint — is rejected on every one of them. **`/v1` is untouched**: the namespace is deliberately `/api/`, off the wire, so nothing here can be mistaken for or collide with what a real `ant` CLI speaks, and its paths mirror the reference console's own segment-for-segment (observed live 2026-08-10) rather than inventing a house convention — which is now the standing rule for any console-facing endpoint. Issuance is refused on a `cloud` environment, whose work the platform's own executor consumes in-process holding no key at all, and on an archived one. Four departures from the observed dialect are deliberate and registered in [docs/DIVERGENCES.md](docs/DIVERGENCES.md): our own `sk-map-env01-` key prefix rather than an Anthropic-look-alike, `envkey_` row ids rather than bare UUIDs (kept out of the wire-prefix set, so a private identifier cannot widen the id shape every `/v1` path accepts), no copied `authorization_details` — the reference's `actions` list is demonstrably narrower than what the key actually authorizes, and echoing a security claim we neither generate nor enforce would be a lie — and the house error envelope. The end-to-end path is pinned by test rather than asserted: a key issued through the endpoint polls the real `/v1/environments/{id}/work/poll`, and after a revoke through the endpoint the same poll is a 401.
