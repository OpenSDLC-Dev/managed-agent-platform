- **An answer's `session_thread_id` no longer refuses it** ([#841](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/841)) — A `user.tool_confirmation`, `user.tool_result` or `user.custom_tool_result` whose `session_thread_id` names another thread, an unknown one or no thread id at all was a 400; it is now accepted and stored, and echoed, on the thread of the call it answers, as the reference was recorded doing for a confirmation. A value that is not a string is still refused.
