- **A `system.message` stays accepted on every model, by decision** ([#553](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/553)) — the reference passes the event to the model as a mid-conversation `role: "system"` message. On a model without support for that, such as Claude Haiku 4.5, it refuses the event with `400 invalid_request_error`. This platform still accepts it on every model and appends its text to the system prompt, which every model and every route can take. So the model reads the text ahead of the whole conversation, not at its place in it. [docs/DIVERGENCES.md](./docs/DIVERGENCES.md) records the three reasons and what the reference was recorded doing.
