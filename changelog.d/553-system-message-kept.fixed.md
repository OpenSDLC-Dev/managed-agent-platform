- **A `system.message` stays accepted on every model, by decision** ([#553](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/553)) — the reference turns the event into a mid-conversation `role: "system"` message, which only some models accept. On Claude Haiku 4.5, it was recorded refusing the event with `400 invalid_request_error`. This platform still accepts the event on every model, when it follows a `user.message` or a tool result as the SDK requires. It appends the event's text to the system prompt, which needs no support for mid-conversation system messages. So the model reads the text ahead of the whole conversation, not at its place in it. [docs/DIVERGENCES.md](./docs/DIVERGENCES.md) records the three reasons and what the reference was recorded doing.
