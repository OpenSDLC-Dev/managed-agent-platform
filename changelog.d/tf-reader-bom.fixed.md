- **A UTF-8 BOM hid every block in a `.tf` file from both readers** ([#765](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/765)) — a block header is anchored with `^\s*`, which matches no BOM, so a file beginning with one was read as holding no `resource` and no `module` at all, and `make gcp-split-check` and `make gcp-kms-role-check` reported success over whatever was in it. Terraform parses such a file — `terraform fmt -check` reports formatting drift and no diagnostic — so refusing it would reject configuration the binary accepts. Both readers now drop a leading BOM on decode instead.
