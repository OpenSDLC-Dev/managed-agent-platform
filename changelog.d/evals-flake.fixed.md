- **A turn that fails on an incomplete tool call says how its stream ended** — the session.error message now ends with the stop reason and, when the endpoint reported one, the output token count, for example `(stop_reason max_tokens, 8192 output tokens)`. A stream that ended without a stop reason says so, together with the stream's own error. This covers both a tool input that is not a complete JSON object and a stream that stops with a tool block still open, so a call the output cap cut off can be told from one the model malformed.
