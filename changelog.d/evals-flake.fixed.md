- **A model stream that ends early says how far it got** — when the anthropic adapter fails a stream that ended before message_stop, or one that left a tool block open under a stop reason that does not explain it, the error now ends with the stop reason and, when the endpoint reported usage, the output token count, for example `(stop_reason max_tokens, 8192 output tokens)`. The count is left out when no stop reason arrived, and a stream that failed keeps its own error ahead of the note. Two live-eval dream graders also stop failing sound results: the in-place dream accepts a tombstone that names its successor memory by path, and the hundred-transcript dream accepts more digest threads than batches.
