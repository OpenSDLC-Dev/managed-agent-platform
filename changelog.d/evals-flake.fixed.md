- **A turn that fails on a cut-off tool call says how its stream ended** — when a tool input stops before its JSON object is complete, the turn now reads the stream to its end before it fails, and records what the call spent. Its session.error message ends with the stop reason and the output token count, for example `(stop_reason max_tokens, 8192 output tokens)`. The count is left out when the endpoint reported no usage or no stop reason, and a stream that failed adds its own error. The anthropic adapter adds the same note when a stream ends early: at message_stop with a tool block still open, or without message_stop at all. A count at the route's output cap shows a cut on every route; a direct OpenAI-protocol route reports tool_use as the stop reason for any turn that called a tool. Any other malformed tool input still fails its turn at once. Two live-eval dream graders also stop failing sound results: the in-place dream accepts a tombstone that names its successor memory by path, and the hundred-transcript dream accepts more digest threads than batches.
