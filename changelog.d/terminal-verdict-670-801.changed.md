- **A verdict on an outcome's last evaluation cycle is acknowledged, whatever it is (#670)** — When no further cycle can run (`iteration + 1 >= max_iterations`), one acknowledgment turn now follows a `satisfied` or `failed` verdict before the session idles, as it already followed `max_iterations_reached`; the turn is told the verdict. With budget left, `satisfied` and `failed` still idle directly. This is reading (B) of the one recorded verdict — `satisfied` on the last cycle of a one-cycle budget, followed by an acknowledgment — and is registered as INFERRED in [docs/DIVERGENCES.md](docs/DIVERGENCES.md). On a cloud session the acknowledgment's own idle schedules the idle outputs harvest.
