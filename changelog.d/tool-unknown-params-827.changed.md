- **Sandbox tools refuse input they do not understand, and `grep` lists files by default** ([#827](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/827)) — `bash`, `read`, `write`, `edit`, `glob` and `grep` answer an input property their schema does not declare with a tool error naming it and listing the ones they accept. They used to drop it and run anyway, so a `grep` sent `-i` searched case-sensitively without saying so. This holds on the executor and the BYOC worker, on Anthropic- and OpenAI-protocol routes alike; the OpenAI adapter still strips `additionalProperties` from the schemas. A `grep` call with no `output_mode` now returns the paths of matching files, the reference's default, where it used to return `path:line:text` lines; ask for `"output_mode": "content"` to get those.
