- **Require native login and retire unowned API access (plan 69 slice 7)** — Both servers require a login mode and Console origin. Private APIs and gateway administration accept browser sessions only; public APIs accept owned keys with current-owner authorization. Unowned credentials and historical unowned initiators no longer authorize requests or model work. Gateway grants, key-policy routes and per-key admission are removed; organization limits share each public model alias. Compose, Helm and CD use the native-only Console and a Console-issued CD service-account key. Obsolete tables and existing staging Secret data remain temporarily for the separate cleanup deployment.
