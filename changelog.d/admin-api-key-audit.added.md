- **Audit archived API keys** — Administrators can list and retrieve key metadata through the public Admin API with an `org:admin` CLI OAuth grant. Console deletion revokes the credential and leaves its ID available for audit. Upgrades remove the retired system `bootstrap` keys from the default tenant. Human-issued keys with the same name and historical usage and initiator IDs are preserved. See the [audit procedure](./docs/self-hosted-security.md#audit-archived-api-keys).
