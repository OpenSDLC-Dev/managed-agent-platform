- **Audit archived API keys** — Administrators can list and retrieve key metadata through the public Admin API with an `org:admin` CLI OAuth grant. Console deletion revokes the credential and leaves its ID available for audit. Upgrades remove retired system `bootstrap` keys from the default tenant. Same-name keys with a recorded issuer or owner survive, along with historical usage and initiator IDs. See the [audit procedure](./docs/self-hosted-security.md#audit-archived-api-keys).
