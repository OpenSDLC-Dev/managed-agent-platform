- **The BYOC worker no longer runs an ask-gated tool call before its human answers** — plan 35 slice 4 ([#53](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/53)): a turn that suspends on two `always_ask` calls is released one confirmation at a time, and the `self_hosted` worker's scan read no `evaluated_permission` at all — so the verdict releasing one call could hand it both, running a command nobody had approved. The scan now requires an `allow` `user.tool_confirmation` naming any call whose evaluated permission is not `allow`, the narrowing the platform's own drivers took in slice 3. A call carrying no evaluated permission still reads as allowed, so nothing already on a log changes. It binds every `self_hosted` session, single-agent and coordinator alike; `cloud` sessions have no BYOC worker.
