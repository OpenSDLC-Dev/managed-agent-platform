- **Thinking goes back to the model** (#67, [docs/plan/60_thinking-replay.md](docs/plan/60_thinking-replay.md)) — the brain keeps each committed turn's signed thinking and `redacted_thinking` blocks and sends them back on later requests, as Anthropic, DeepSeek, Kimi and MiniMax document a tool-using conversation must. The wire `agent.thinking` event is unchanged and content-free: the blocks live in a new `thinking_blocks` table (migration 0048), written by the turn's settlement and read by replay alone. A block goes back only to the model id that produced it and only while everything before it in the request is what it was produced under, so a changed system prompt, tool set or model drops the earlier reasoning instead of turning the request into a 400. The anthropic adapter now forwards `signature_delta` and `redacted_thinking`; the OpenAI-protocol adapter is unchanged.
