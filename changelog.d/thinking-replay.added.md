- **Thinking goes back to the model** (#67, [docs/plan/60_thinking-replay.md](docs/plan/60_thinking-replay.md)) — the brain keeps each committed turn's signed thinking and `redacted_thinking` blocks and sends them back on later requests, as Anthropic and DeepSeek document a tool-using conversation must. The wire `agent.thinking` event is unchanged and content-free: the blocks live in a new `thinking_blocks` table (migration 0048), written by the turn's settlement and read by replay alone. A block goes back only to the model id that produced it and only while everything before it in the request is what it was produced under, so a changed system prompt, tool set, model or route drops the earlier reasoning instead of turning the request into a 400 on an endpoint that follows Anthropic's rule (DeepSeek's exception: #883), and a request that fails with blocks to replay drops them, so a refused block cannot wedge a session. A model route that sets one header under two names alike but for case is now refused at startup. The anthropic adapter now forwards `signature_delta`, `redacted_thinking`, and text sent whole on a block's start; the OpenAI-protocol adapter is unchanged.
