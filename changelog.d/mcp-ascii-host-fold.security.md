- **The MCP bearer no longer follows a host that only Unicode folding calls the same (#609)** — `internal/mcp`'s `sameHost`, which decides whether a vault-resolved token rides a request, compared with `strings.EqualFold`. Unicode's fold orbits merge characters IDNA keeps apart: `σ.example` with `ς.example`, and `ſtrasse.example` with `strasse.example`, each pair punycoding to two different registrable names. Calling them one origin sent the bearer to the second. Case folding a hostname is an ASCII operation and is now done that way, which is what `internal/egress` and `internal/vaultresolve` already did — this was the last of the three that did not. One case goes the other way and is deliberate: U+212A (KELVIN SIGN) is folded onto `k` by IDNA too, so `K.example` and `k.example` really are one domain and the token is now withheld from it. A withheld bearer costs a 401; a wrongly-shared one costs the secret. No production path was reachable before the fix, because this repo's MCP clients refuse redirects — a supplied redirect-following client would have made it live.
