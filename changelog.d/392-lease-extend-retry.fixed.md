- **A slow lease renewal no longer shortens the next one's budget, abandoning a turn whose lease is still live** ([#392](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/392)) — the shared lease keeper renews a claimed work item every `ttl/3` and bounds each attempt so it cannot outlive the lease it is racing. That bound was the constant `ttl - ttl/3`, which is only the right number when the tick is punctual. A `time.Ticker` buffers one tick and drops the rest, so a renewal that takes longer than an interval is followed by a tick *already waiting*: the next attempt begins the moment the slow one returns, not an interval later, and its deadline then fell as much as a third of a lease **inside** the lease that renewal had just bought. A database slow enough to overrun it made the keeper fail with `extend …: context deadline exceeded` and cancel work nothing else could yet claim — at the two-minute production `LeaseTTL`, up to forty seconds of live lease discarded, taking with it a model turn that may already have streamed a real answer, or a tool run in progress. Each attempt is now bounded by the time measured locally since the last successful renewal returned: a punctual tick still gets `ttl - ttl/3`, a late one gets only the remainder, and a tick arriving after that budget is spent reports the lease lost without dialing the database at all. Because the stamp is taken when a renewal *returns* rather than when the database committed it, the bound is never shorter than what the lease really has left — which is what makes a timeout mean the lease has lapsed. It does not mean the row is free: an `Extend` that commits while the client's deadline fires renews a lease the caller never sees, which no budget arithmetic can reach, and is filed as [#400](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/400). Both the brain's turn loop and the executor's item processing use this one keeper, so both are fixed. Pinned by a regression test that makes `Extend` genuinely slow with queued Postgres row locks rather than simulating it, and which fails against the old budget.
