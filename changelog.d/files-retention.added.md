- **An expired file eventually leaves the registry** — the controlplane sweeps hourly for files whose expiry passed more than 30 days ago and removes the row and its object together, which is the end of the grace window the reference publishes: past `expires_at` the content stops being served immediately, while the metadata "remains readable for up to 30 days". Until now nothing removed them, so an expired file's metadata would have been readable forever. A file with no expiry is never a candidate, the window is measured from `expires_at` rather than from the upload, and each sweep is bounded so a first pass over a backlog cannot hold one transaction open for as long as the object store takes (#655).
