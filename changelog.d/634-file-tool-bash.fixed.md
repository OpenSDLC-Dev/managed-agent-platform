- **Two file-tool errors no longer tell the model to use `bash`** ([#634](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/634)) — the first answers `write` or `edit` on a target they cannot replace, such as a device node or a file bind-mounted into the sandbox. The second answers `read` or `edit` on a file over the 4 MiB limit, and now says that a `view_range` does not lift it. Both used to advise bash redirection, or `head`/`tail`/`sed` on a slice. That sent a session with `bash` disabled, such as an `update_existing` dream, to a tool it was never offered, and spent a turn on the refusal. Each result now states the constraint and names only the tools that answer it. A session that has `bash` can still use it.
