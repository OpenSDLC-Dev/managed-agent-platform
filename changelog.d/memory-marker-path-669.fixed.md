- **A memory at `/.anthropic-memory-store` is created, not refused, and never lands on the marker** ([#669](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/669)) — `POST /v1/memory_stores/{id}/memories` at the marker file's own path now answers 200 and the memory lists like any other, as the reference answers it; it used to be a 400. Accepting it alone would have landed its content over the mount's marker, leaving the directory untrusted and every later write of the session silently withheld, so both consumers now skip it with a warning, as the reference's own worker does: the executor when it lands or syncs a store, the BYOC worker when it lists one. It stays in the store and counts toward the 2,000-memory cap. A rename onto that path is still a 400 — unrecorded on the reference, and registered in docs/DIVERGENCES.md as this platform's choice.
