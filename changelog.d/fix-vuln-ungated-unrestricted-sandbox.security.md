- **Unrestricted cloud sandboxes now provision the per-session egress gate and Helm enables it by default** — `internal/executor` now requests a per-session egress gate for every cloud session (including `networking.type: unrestricted` sessions without attached vaults) whenever `EXECUTOR_GATE_IMAGE` and `CONTROLPLANE_URL` are configured, so unrestricted sandboxes traverse the gate's owner-match firewall and `dialguard.IPAllowed` address floor (blocking cloud metadata / link-local, loopback, unspecified, multicast, and embedded IPv6 transition targets) rather than joining the host bridge or pod network directly. The Helm chart (`deploy/helm/managed-agent-platform/values.yaml`) now defaults `executor.gateImage` to `ghcr.io/opensdlc-dev/managed-agent-platform/gate:0.6.0` instead of empty; set `executor.gateImage=""` only to opt out explicitly. RFC 1918 destinations remain reachable under `unrestricted` networking by design and still require a Kubernetes `NetworkPolicy` or `networking.type: limited` to block in-cluster services.
