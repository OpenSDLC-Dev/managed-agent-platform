- **The brain routes through the model gateway by default** (plan 59 slice 5, #897) — compose mounts `model-providers.gateway.json`, one route sending every model to the gateway under `BRAIN_API_KEY`, which `.env` must now set, different from `CONTROLPLANE_API_KEY`. The Helm chart turns `modelgateway.enabled` on, writes that route into a ConfigMap, and needs `brain.apiKey` (Secret key `brain-api-key`) and a credential cipher; `brain.gatewayRoute` adds the route's other fields, `max_tokens` among them; `brain.modelProviders` applies only with the gateway off, and setting both fails the render. Model turns fail until the gateway's catalogue names a deployment for the agent's model. To keep routing the brain yourself, set `modelgateway.enabled=false` (with `--set`, never `--set-string`); an `existingSecret` then still carries `model-providers.json`, and with the gateway on it carries `brain-api-key` instead. A `--reuse-values` upgrade keeps the installed chart's default, off; run the upgrade that turns it on while no turns run. GCP staging keeps the gateway off.
