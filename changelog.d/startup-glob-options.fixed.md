- **The outputs harvest and the `glob` tool find files on an image whose startup sets glob options** (found while working on [#921](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/921)) — an image's `ENV BASH_ENV` file runs before each of the platform's own scripts in the sandbox, and the options it set carried into them. Under noglob (`set -f`) the outputs harvest published no files and `glob` matched nothing. A `GLOBIGNORE` hid matches, failglob made a `glob` that matched nothing an error, and nocaseglob or extglob changed what a pattern matched. Each script the platform runs in the sandbox for its own work now starts by putting bash's defaults back for noglob, `GLOBIGNORE`, `GLOBSORT` and the `shopt` options `dotglob`, `extglob`, `failglob`, `globstar`, `nocaseglob` and `nullglob`. The repository-skills listing, which undid them itself since #933, now relies on the same start. The model's own commands still run under what the file set.
