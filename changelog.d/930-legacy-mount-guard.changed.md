- **A repository clone that fails in the sandbox after the fetch reports reason `internal`** ([#930](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/930)) — a `github_repository_clone_error` for a failure shipping the fetched repository into the sandbox, or extracting it there, carried reason `network`, the git host's, whenever the error looked like a network failure: a dropped exec stream, or a mount path such as `/workspace/EOF` in its text. It now carries `internal`, and a deadline there still carries `timeout`. The error is now deduped per resource, reason and message, not per resource and reason, so a mount path's refusal reaches the client after an earlier generic `internal` failure.
