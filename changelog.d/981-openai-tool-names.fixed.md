- **A tool name of 65 to 128 characters works on a model route that speaks the OpenAI protocol** ([#981](https://github.com/OpenSDLC-Dev/managed-agent-platform/issues/981)) — a Chat Completions function name stops at 64 characters, and OpenAI refused the whole request over one longer name, so a custom tool of that length, or an MCP tool whose `mcp__{server}__{tool}` name is, failed every turn of such a session. The brain's OpenAI provider and the model gateway's conversion to a Chat Completions upstream now send such a name as its first 47 characters, `_` and 16 hex digits of its SHA-256, and read the model's call back under the tool's own name, so the session's events never show the short form. A request with two tools whose names would go out as one is refused. A Gemini upstream takes 128 already.
