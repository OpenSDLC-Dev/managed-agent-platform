- **Memory-version retention prunes at startup instead of an hour later** — `time.NewTicker` does not fire when it is created, so the control plane's memory-version sweep waited a full hour before its first pass. A deployment that restarts the control plane more often than that — continuous delivery on every merge, a crash-looping replica, autoscaler churn — never reached the prune at all, and its retained versions accumulated forever, which is the same outcome as not running the sweep. The pass now runs before the first wait, the order the expired-file sweep already took; the statement is idempotent, so every replica taking a pass at boot costs duplicate queries and nothing else (#695).
